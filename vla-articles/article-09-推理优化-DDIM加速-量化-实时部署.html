2.2 DPM-Solver：更高质量的步数压缩


DDIM 在大步数时质量好，但小步数时质量下降明显。


DPM-Solver（Diffusion Probabilistic Model Solver）是一个更先进的采样器，可以在更少步数下达到更高质量：


# DPM-Solver-2（2阶）
@torch.no_grad()
def dpm_solver_sample(model, obs, lang, T=100, num_steps=10):
    """
    DPM-Solver：比 DDIM 更高效的采样器
    
    核心思想：用指数积分器和高阶 ODE 求解
    比 DDIM 在相同步数下质量更高
    """
    timesteps = torch.linspace(1, 0, num_steps + 1)
    
    x = torch.randn(obs.shape[0], model.action_dim, device=obs.device)
    
    # DPM-Solver-2 核心步骤
    for i in range(num_steps):
        t, t_next = timesteps[i], timesteps[i + 1]
        
        lambda_t = -0.5 * torch.log(torch.tensor(t))
        lambda_t_next = -0.5 * torch.log(torch.tensor(t_next))
        delta_lambda = lambda_t_next - lambda_t
        
        # 预测 x_{t_next}
        eps = model(x, obs, lang, t * model.T)
        
        # DPM-Solver-2 预测
        x = x + (t - t_next) * eps  # 一阶项
        # 二阶修正（更精确）
        if i < num_steps - 1:
            eps_next = model(x, obs, lang, t_next * model.T)
            x = x + (t - t_next) / 2 * (eps_next - eps)
    
    return x

2.4 Progressive Distillation（知识蒸馏）


更进一步，可以用知识蒸馏把 DDIM 的多步采样蒸馏到少步：


# 蒸馏训练：用 teacher（T步）指导 student（t步）
def distillation_loss(student_output, teacher_output):
    """
    student: 5 步采样结果
    teacher: 20 步采样结果
    """
    return F.mse_loss(student_output, teacher_output.detach())

蒸馏后，5 步的 student 可以接近 20 步 teacher 的质量。

四、INT8 量化


4.1 量化原理


FP16/FP32 的问题是：对于 VLA 模型的某些层（尤其是 Action Head），权重和激活值的动态范围不大，用 INT8（8位整数）足以表达。


FP16: 1 sign + 5 exp + 10 mantissa
INT8: 1 sign + 7 mantissa（256 个离散值）

量化：w_fp16 = scale * w_int8 + zero_point
反量化：w_int8 = round((w_fp16 - zero_point) / scale)

4.2 PTQ（Post-Training Quantization）


训练后量化，不需要重新训练：


import torch.quantization

# 动态量化（最简单，但效果一般）
model_int8 = torch.quantization.quantize_dynamic(
    model, {nn.Linear, nn.MultiheadAttention},
    dtype=torch.qint8
)

# 静态量化（需要校准数据，效果更好）
model.eval()
model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
torch.quantization.prepare(model, inplace=True)

# 校准（用一小批真实数据）
with torch.no_grad():
    for batch in calibration_data:
        model(batch)

# 转换
torch.quantization.convert(model, inplace=True)

4.3 QAT（Quantization-Aware Training）


如果 PTQ 精度损失太大，用 QAT 在训练中模拟量化：


# 在训练中使用伪量化
from torch.quantization import FakeQuantize

# 在 Linear 层后加伪量化
class QuantizedLinear(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(out_features, in_features))
        self.weight_fake_quant = FakeQuantize()
    
    def forward(self, x):
        w = self.weight_fake_quant(self.weight)
        return F.linear(x, w)

五、CUDA Graphs：消除 kernel 启动开销


5.1 问题


每次 CUDA kernel 启动都有 4~10μs 开销。对于几十个小 kernel 串行调用，累计开销可达 0.5~2ms。


5.2 解决方案：CUDA Graphs


CUDA Graphs 把整个前向过程打包成一个有向无环图（DAG），一次启动即可执行整个图：


import torch.cuda.graphs

# Step 1: 把推理过程包装成静态图
graph = torch.cuda.graphs

# 需要先把输入/输出设为 non-pinned memory
model = model.cuda()
obs = obs.cuda().contiguous()
lang = lang.cuda().contiguous()

# Step 2: 捕获图
s = torch.cuda.Stream()
s.wait_stream(torch.cuda.current_stream())
with torch.cuda.stream(s):
    for _ in range(3):  # warmup
        output = model(obs, lang)
output.wait_stream(s)
torch.cuda.current_stream().wait_stream(s)

# 捕获
g = graph.capture_graph(model.graph, input_args=(obs, lang))

# Step 3: 重放（无 Python 开销）
g.replay()  # 比普通调用快 0.5~2ms
output = obs  # 输出已在 obs 中


六、Batch 推理优化


6.1 静态 vs 动态 Batch


机器人的特点是实时响应，通常 batch_size=1。但 batch_size=1 时 GPU 利用率极低。


解决方案：请求队列 + micro batching


class InferenceQueue:
    """
    请求队列：将多个实时请求攒批处理
    """
    def __init__(self, max_batch_size=4, max_wait_ms=5):
        self.queue = []
        self.max_batch_size = max_batch_size
        self.max_wait_ms = max_wait_ms
    
    def add(self, obs, lang):
        event = {'obs': obs, 'lang': lang, 'ready': False}
        self.queue.append(event)
        
        if len(self.queue) >= self.max_batch_size:
            return self._run_batch()
        
        # 超时机制
        threading.Timer(self.max_wait_ms / 1000, 
                       lambda: self._process_if_ready(event))
        return None
    
    def _run_batch(self):
        if not self.queue:
            return None
        
        obs_batch = torch.stack([e['obs'] for e in self.queue])
        lang_batch = torch.stack([e['lang'] for e in self.queue])
        
        with torch.no_grad():
            output = model(obs_batch, lang_batch)
        
        # 分发结果
        for i, event in enumerate(self.queue):
            event['result'] = output[i]
            event['ready'] = True
            event['cv'].notify()
        
        self.queue = []
        return output
    
    def _process_if_ready(self, event):
        if not event['ready'] and event in self.queue:
            self._run_batch()

知识点关键结论
DDIM 步数目标 10 步，20 步是底线，配合 DPM-Solver 可更少
DPM-Solver比 DDIM 同等步数质量高 5~10%

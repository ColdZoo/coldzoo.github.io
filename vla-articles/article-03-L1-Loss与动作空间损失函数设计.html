一、为什么动作空间不能用简单 MSE


1.1 高维动作空间的问题


机器人的动作空间通常是 7~14 维（末端位姿 + 夹爪），每个维度代表不同的物理量：位置（米）、旋转（四元数或欧拉角）、夹爪开度（0~1）。


用 MSE/L2 Loss 训练时：


$$\mathcal{L}_{\text{MSE}} = \frac{1}{D} \sum_{d=1}^{D} (a_d - \hat{a}_d)^2$$


问题一：维度灾难


高维空间中，MSE 的梯度会被所有维度共同贡献，但实际有效的梯度信号可能只来自少数几个"活跃"维度。


问题二：离群动作的梯度爆炸


机械臂在某些状态下需要执行离群动作（比如紧急避障时的大幅度关节运动）。MSE 对离群点的惩罚是平方级增长——一个 outlier 维度可以把整个梯度拉偏：


$$\frac{\partial \mathcal{L}}{\partial \hat{a}_d} = 2(a_d - \hat{a}_d)$$


当 $|a_d - \hat{a}_d| = 10$（机器人避障动作），单维梯度就是 20，是正常动作（差 0.5）的 40 倍。


问题三：多模态被抹平


同一指令可能对应多种合理动作分布，比如抓取物体可以从左侧或右侧出发。MSE 训练会迫使模型预测所有模态的均值，这个均值动作可能对任何模态都不是最优的。



二、L1 Loss 的理论基础


2.1 定义


$$\mathcal{L}_{\text{L1}} = \frac{1}{D} \sum_{d=1}^{D} |a_d - \hat{a}_d|$$


关键性质：稀疏梯度


L1 损失的梯度是常数（对正负误差分别 +1 和 -1），不随误差大小增长：


$$\frac{\partial \mathcal{L}}{\partial \hat{a}_d} = \text{sign}(a_d - \hat{a}_d) \in \{-1, 0, +1\}$$


这意味着：

  • 大误差维度不会主导梯度
  • 所有维度均匀贡献梯度
  • 对离群点天然鲁棒

2.2 统计学视角：L1 vs L2 本质是均值 vs 中位数的选择


度量优化目标对应损失
均值（Mean）最小化平方期望 $\arg\min \mathbb{E}[(a - \hat{a})^2]$L2 / MSE
中位数（Median）最小化绝对期望 $\arg\min \mathbb{E}[a - \hat{a}]$L1 / MAE
众数（Mode）最大化概率密度0-1 损失（不可微）

为什么中位数更适合机器人？


当数据是多峰的（有多个合理动作模态），L2 的均值可能落在所有模态之间——这是最差的动作！


而 L1 的中位数，在多模态分布下往往落在某个真实模态附近，表现更稳定。


2.3 扩散模型中的 L1 Loss


在扩散模型的训练中，标准损失是预测噪声 $\epsilon$：


$$\mathcal{L} = \mathbb{E}_{t, \epsilon, a_0, c} \|\epsilon - \epsilon_\theta(a_t, c, t)\|^2 \quad \text{（L2 版本）}$$


如果预测目标换成 velocity $v = a_0 - a_T$：


$$\mathcal{L} = \mathbb{E}_{t, v, a_0, a_T, c} \|v - v_\theta(a_t, c, t)\|_1$$


这是 π0 和 GR00T-N1 论文中都提到的技巧：用 L1 预测 velocity 效果更好。


原因：

  • Velocity 的分布通常是多峰的（快速运动 vs 精细调整）
  • L1 避免了速度为零时的小梯度消失问题
  • L1 的均匀梯度让所有动作维度同时受益


    • 三、Huber Loss：L1 和 L2 的自适应混合


    3.1 定义


    $$\mathcal{L}_{\delta}(a, \hat{a}) = \begin{cases} \frac{1}{2}(a - \hat{a})^2 & \text{if } |a - \hat{a}| \leq \delta \\ \delta \cdot |a - \hat{a}| - \frac{1}{2}\delta^2 & \text{if } |a - \hat{a}| > \delta \end{cases}$$


    其中 $\delta$ 是切换阈值（通常设为 1.0 或归一化后的 1.0）。


    直观理解：

    • 小误差（$< \delta$）→ 用 L2（精确优化二次区域）
    • 大误差（$> \delta$）→ 切换到 L1（避免梯度爆炸）

    3.2 为什么 Huber Loss 在机器人控制中很合理


    机器人的动作误差分布通常是重尾分布（heavy-tailed）：


    • 95% 的时间：精细操作，误差小（0.01~0.1 量级）
    • 5% 的时间：避障/抓取，误差大（0.5~2.0 量级）

    Huber Loss 在小误差区域用 L2（精细优化），在大误差区域切换 L1（鲁棒处理）。这是自适应的，不需要手动判断哪个维度是离群点。


    3.3 δ 参数的调节建议


    δ 值行为适用场景
    δ = 0.1几乎全程 L2精细操作任务（定位精度要求 < 1mm）
    δ = 1.0中等切换点通用机器人操作
    δ = 5.0更多 L1 区域强干扰环境、避障优先
    δ = 自适应根据动作归一化推荐方案：$\delta = \text{median}(\a - \hat{a}\) \times 1.35$（类似 MAD 估计）


    四、Smooth-L1（伪 Huber）及其变体


    4.1 Smooth-L1 / Charbonnier Loss


    $$\mathcal{L}_{\text{smooth-L1}} = \sqrt{(a - \hat{a})^2 + \epsilon^2} - \epsilon$$


    其中 $\epsilon$ 是一个小常数（e.g., 1e-6），防止梯度为零。


    特点：

    • 处处可微（比 L1 更适合反向传播）
    • 当误差小时近似 L2，误差大时近似 L1
    • 本质上是 Huber Loss 的平滑版本

    4.2 Charbonnier Loss 在扩散策略中的应用


    多个 2024-2025 年的机器人扩散论文（如 PDFactor, Diffusion Policy 原始论文）都使用了 Charbonnier Loss：


    def charbonnier_loss(pred, target, eps=1e-6):
    """Charbonnier Loss (= Smooth-L1 in some variants)"""
    diff = pred - target
    return torch.sqrt(diff * diff + eps) - eps

    4.3 Generalized Charbonnier Loss


    在多任务学习中，不同动作维度的量纲可能不同（末端位置 vs 夹爪开度）。可以引入维度自适应权重：


    $$\mathcal{L} = \sum_{d=1}^{D} w_d \cdot \sqrt{(a_d - \hat{a}_d)^2 + \epsilon_d^2}$$


    其中 $w_d$ 可以根据动作维度的方差动态调整：


    $$w_d = \frac{1}{\sigma_d + \epsilon}, \quad \sigma_d = \text{std}(a_d \text{ in batch})$$



    五、Log-Sum-Exp 损失：端到端的鲁棒设计


    5.1 定义


    $$\mathcal{L}_{\text{LSE}} = \frac{1}{\lambda} \log\left(\sum_{d=1}^{D} \exp(\lambda |a_d - \hat{a}_d|)\right)$$


    当 $\lambda \to \infty$ 时，Log-Sum-Exp 近似于 $\max_d |a_d - \hat{a}_d|$（即最差维度的误差）。

    当 $\lambda \to 0$ 时，Log-Sum-Exp 近似于均值误差。


    5.2 为什么有用


    Log-Sum-Exp 是一个软化的最大范数：


    • 当所有维度误差相近时 → 近似均值（L2/L1 行为）
    • 当某个维度误差突出时 → 放大该维度影响（比 L1 更敏感）
    • 避免所有维度被均匀惩罚：机器人动作中，夹爪开度错 0.1 比末端位置错 0.01 更不能接受


    六、多模态动作分布的专门损失设计


    6.1 问题的本质


    传统 MSE/L1/L2 都是单峰损失，但机器人动作天然是多模态的。


    举例："把杯子放到桌子中央"

    • 模态 A：从左侧接近、抓取、放置（更自然）
    • 模态 B：从右侧接近、抓取、放置（同样合理）

    用 MSE 训练 → 学会的是 A 和 B 的均值轨迹（一个四不像）

    用 L1 训练 → 学会的是某个模态，但一旦数据不平衡，另一个模态会消失


    6.2 解决方案一：Mixture-of-Experts 损失


    在 GO-1 的 MoE Action Head 中，每个专家负责不同的动作模态：


    动作先验 z ~ q(z | obs, instruction)
    → 路由器选择 expert k
    → expert k 预测动作
    → 损失 = L1(a, pred_k) + λ · KL(q(z) || p(z))  (鼓励多模态)

    关键：KL 散度项强制多个专家都被激活，避免单一模态主导。


    6.3 解决方案二：对抗式动作建模


    用 GAN-style 判别器来区分真实动作和预测动作：


    $$\mathcal{L}_G = -\mathbb{E}[\log D(a_{\text{real}}, c)] - \mathbb{E}[\log(1 - D(G(c), c))]$$


    判别器 $D$ 迫使生成器 $G$ 产生真实分布的动作，而不是均值。


    6.4 解决方案三：Contrastive Learning for Actions


    对于每个状态-动作对 $(s, a)$，构造正负样本：


    $$\mathcal{L}_{\text{contrast}} = -\log \frac{\exp(\text{sim}(f(s), f(a^+)) / \tau)}{\sum_{a^-} \exp(\text{sim}(f(s), f(a^-)) / \tau)}$$


    其中 $a^+$ 是正向动作，$a^-$ 是负向动作（同一状态下的其他动作）。


    这让模型在动作空间中学习区分不同模态，而不是被迫预测均值。



    七、扩散模型中损失函数的具体实现


    7.1 标准 L2 扩散损失


    def diffusion_l2_loss(model, obs, action, t):
    """
    标准 DDPM L2 损失
    model: noise prediction network
    """
    batch_size = action.shape[0]
    
    # 采样 t 和噪声
    t = torch.randint(0, model.T, (batch_size,), device=action.device)
    eps = torch.randn_like(action)
    
    # 前向扩散
    sqrt_alpha_bar = model.sqrt_alphas_bar[t][:, None]
    sqrt_one_minus = model.sqrt_one_minus_alphas_bar[t][:, None]
    noisy_action = sqrt_alpha_bar * action + sqrt_one_minus * eps
    
    # 预测噪声
    eps_pred = model(noisy_action, obs, t)
    
    # L2 损失
    return ((eps - eps_pred) ** 2).mean()

    7.2 L1 扩散损失（推荐用于机器人）


    def diffusion_l1_loss(model, obs, action, t):
    """L1 损失，扩散模型专用"""
    batch_size = action.shape[0]
    
    t = torch.randint(0, model.T, (batch_size,), device=action.device)
    eps = torch.randn_like(action)
    
    sqrt_alpha_bar = model.sqrt_alphas_bar[t][:, None]
    sqrt_one_minus = model.sqrt_one_minus_alphas_bar[t][:, None]
    noisy_action = sqrt_alpha_bar * action + sqrt_one_minus * eps
    
    eps_pred = model(noisy_action, obs, t)
    
    # L1 损失（推荐）
    return torch.abs(eps - eps_pred).mean()

    7.3 Huber 扩散损失


    def diffusion_huber_loss(model, obs, action, t, delta=1.0):
    """Huber 损失的扩散版本"""
    batch_size = action.shape[0]
    
    t = torch.randint(0, model.T, (batch_size,), device=action.device)
    eps = torch.randn_like(action)
    
    sqrt_alpha_bar = model.sqrt_alphas_bar[t][:, None]
    sqrt_one_minus = model.sqrt_one_minus_alphas_bar[t][:, None]
    noisy_action = sqrt_alpha_bar * action + sqrt_one_minus * eps
    
    eps_pred = model(noisy_action, obs, t)
    
    # 扩散模型预测的是噪声
    error = eps - eps_pred  # [batch, action_dim]
    
    # Huber 损失
    abs_error = torch.abs(error)
    quadratic = torch.clamp(abs_error, max=delta)
    linear = abs_error - quadratic
    loss = 0.5 * quadratic ** 2 + delta * linear
    
    return loss.mean()

    7.4 多任务加权损失


    def weighted_diffusion_loss(model, obs, action, t, 
                             loss_type='huber',
                             delta=1.0,
                             dim_weights=None):
    """
    多维度自适应加权损失
    
    Args:
        dim_weights: [D] 权重向量，默认 None 时均匀
    """
    batch_size = action.shape[0]
    action_dim = action.shape[1]
    
    t = torch.randint(0, model.T, (batch_size,), device=action.device)
    eps = torch.randn_like(action)
    
    sqrt_alpha_bar = model.sqrt_alphas_bar[t][:, None]
    sqrt_one_minus = model.sqrt_one_minus_alphas_bar[t][:, None]
    noisy_action = sqrt_alpha_bar * action + sqrt_one_minus * eps
    
    eps_pred = model(noisy_action, obs, t)
    error = eps - eps_pred
    
    if dim_weights is None:
        # 基于动作维度方差的动态权重
        with torch.no_grad():
            dim_weights = 1.0 / (torch.var(action, dim=0) + 1e-6)
            dim_weights = dim_weights / dim_weights.sum() * action_dim
    
    if loss_type == 'l1':
        per_dim_loss = torch.abs(error)
    elif loss_type == 'huber':
        abs_error = torch.abs(error)
        quadratic = torch.clamp(abs_error, max=delta)
        linear = abs_error - quadratic
        per_dim_loss = 0.5 * quadratic ** 2 + delta * linear
    else:
        per_dim_loss = error ** 2
    
    # 按维度加权
    weighted_loss = per_dim_loss * dim_weights[None, :]
    return weighted_loss.mean()


    八、比赛实战建议


    8.1 损失函数选择路线图


    你的任务特点 → 推荐损失函数

精细操作（误差 < 5mm）：
  → Smooth-L1 (Charbonnier)，delta=0.1

通用操作（日常家务/工厂任务）：
  → Huber Loss，delta=1.0（首选）或 L1

避障/对抗性环境（经常有大误差）：
  → L1 或 Huber，delta=5.0

多模态任务（同一指令多种抓法）：
  → L1 + MoE loss 或 Contrastive Action Loss

数据噪声大（演示数据质量一般）：
  → Huber delta=2.0 或 Log-Sum-Exp

    8.2 δ 参数的动态调节


    不要固定 δ，建议在训练中使用退火策略：


    # 训练早期：大 δ，鼓励探索
# 训练晚期：小 δ，精细收敛
delta_schedule = {
    0: 5.0,      # 初期
    5000: 2.0,   # 中期
    15000: 1.0,  # 后期
    30000: 0.5   # 收敛期
}

    8.3 归一化是前提


    在用任何损失函数之前，必须对动作进行归一化：


    # 方案一：简单 min-max 归一化
action_norm = (action - action_min) / (action_max - action_min + eps)

# 方案二（推荐）：z-score 归一化
action_mean = action.mean(dim=0, keepdim=True)
action_std = action.std(dim=0, keepdim=True) + eps
action_norm = (action - action_mean) / action_std

    不归一化会导致不同维度的动作量纲差异巨大，MSE/L1 的数值范围不一致。


    8.4 实验验证建议


    强烈建议在调参前做一次损失函数对比实验（在一小部分数据上）：


    损失函数验证集 MSE（低=好）验证集多模态保真度离群点鲁棒性
    L2 (baseline)—差差
    L1✅ 好
    Huber δ=1.0✅ 好

    九、本篇要点总结


    知识点关键结论
    L1 vs L2 的本质L2 = 均值，L1 = 中位数，中位数更适合多模态动作
    离群点问题L1 梯度有界（±1），L2 梯度随误差增长
    Huber Loss自适应 L1/L2，通用机器人操作首选
    δ 参数精细任务用小 δ，强干扰用大 δ，建议用退火 schedule
    Charbonnier处处可微，Huber 的平滑替代，diffusion policy 原版使用
    维度自适应权重不同量纲的动作维度（位置 vs 夹爪）需要不同权重
    归一化是前提不管用什么损失函数，动作必须先归一化

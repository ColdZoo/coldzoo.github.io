一、AgiBot World Challenge 2026 赛题分析

1.3 任务难度分级（实战优先级排序）


Tier 1（优先拿下，成功率容易接近 100%）
├── Hold Pot（持锅）              → 单一动作，保持稳定，最简单
├── Place Block into Box          → 单一目标，精度要求高但动作简单
└── Pour Workpiece                → 单一动作，倾倒轨迹固定

Tier 2（需要调参优化，可以争取 90%+）
├── Sorting Packages              → 多目标但同质，action chunk 不需要太长
├── Open Door                     → 姿态操作，需要正确朝向
└── Take Wrong Item Shelf         → 语义理解 + 抓取，考验 VLM

Tier 3（高难度，需要专项优化）
├── Stock and Straighten Shelf    → 多步骤 + 精确放置，K 需要大
├── Clean the Desktop             → 多目标 + 路径规划
├── Scoop Popcorn                 → 工具使用（勺），比直接抓取难
└── Sorting Packages Continuous   → 超长时序，K=64 不一定够，需要时序策略

综合推荐：

  • Tier 1~2 任务（拿分基本盘）：ACoT-VLA（K=32~64）
  • Tier 3 高难度任务：GO-1 / ViLLA（Latent Action 泛化强，适合新物体/新场景）
  • Place Block / Scoop（精细操作）：π0 + DINOv2 backbone

二、模型选型决策树


你的任务是哪个？
│
├─ Tier 1（Hold Pot / Place Block / Pour Workpiece）
│   ├─ → ACoT-VLA K=32
│   │         loss=huber, cfg_w=1.25
│   │
├─ Tier 2（Sorting Packages / Open Door / Take Wrong Item）
│   ├─ 动作 < 6s → ACoT-VLA K=32~48
│   └─ 需要语义泛化 → GO-1 / ViLLA
│       （Take Wrong Item Shelf 需要理解"错误"的语义）
│
├─ Tier 3（Stock Shelf / Clean Desktop / Scoop Popcorn）
│   ├─ 多目标循环 → ACoT-VLA K=64 + DiT backbone
│   ├─ 工具使用精细 → π0 + DINOv2 backbone
│   └─ 超长时序(>15s) → GO-1 latent action（推荐）
│
├─ Sorting Packages Continuous（连续整理）
│   ├─ 最难长时序任务！
│   ├─ 需要 K=64~128 + 时序 ensemble
│   └─ 推荐 ACoT-VLA + 课程学习（从短任务开始）
│
└─ 通用选项（无特殊偏好）
    └─ ACoT-VLA + SigLIP backbone
      （综合最优，CVPR 2026 官方基线，LIBERO 验证 SOTA）


三、架构配置模板


3.1 ACoT-VLA 参赛配置


# ACoT-VLA 比赛配置（按任务分层）
acot_config = {
    # === Backbone ===
    'vision_encoder': 'siglip_vitl16_384',
    'vision_freeze': True,              # 数据少时冻结 VLM
    'lang_encoder': 'bert-base-chinese', # 中文指令支持

    # === ACoT 组件 ===
    'ear_dim': 512,                     # 显式动作推理器维度
    'iar_dim': 512,                     # 隐式动作推理器维度
    'semantic_dim': 256,                # 中间语义层维度（桥接感知与动作）

    # === Action Chunk（关键！按任务选） ===
    'action_chunk_size': {
        'Tier1_Task': 16,               # Hold Pot, Pour Workpiece, Place Block
        'Tier2_Task': 32,               # Sorting Packages, Open Door, Take Wrong Item
        'Tier3_Task': 64,               # Stock Shelf, Scoop Popcorn, Clean Desktop
        'Continuous_Task': 64,           # Sorting Packages Continuous
    },
    'observation_history': 16,          # 历史帧数

    # === Diffusion ===
    'diffusion_steps': 100,             # 训练步数
    'inference_steps': 10,              # DDIM 推理步数（目标 < 20ms 总延迟）
    'sampler': 'dpm_solver',            # 推荐用 DPM-Solver，质量更好

    # === Loss ===
    'loss_type': 'huber',               # huber 对离群点鲁棒
    'huber_delta': 1.0,

    # === CFG（调参优先级最高） ===
    'cfg_dropout': 0.1,                 # 条件 dropout
    'cfg_w': {
        'Precision_Task': 1.5,           # Place Block into Box（精度要求高）
        'Semantic_Task': 1.25,           # Take Wrong Item Shelf（语义理解为主）
        'Default': 1.25,
    },

    # === Training ===
    'precision': 'bf16',
    'per_gpu_batch': 8,
    'gradient_accum': 4,
    'lr': 1e-4,                         # VLM 冻结时
    'ema_decay': 0.9999,
    'gradient_clip': 1.0,

    # === 推理强化项 ===
    'use_ema': True,
    'use_temporal_ensemble': True,
    'num_ensemble': 4,
}

任务 → Chunk Size 速查表：


K=16  → Hold Pot, Pour Workpiece
K=32  → Place Block, Sorting Packages, Open Door, Take Wrong Item
K=64  → Stock Shelf, Scoop Popcorn, Clean Desktop, Sorting Packages Continuous

注意：Sorting Packages Continuous 是最难任务：

  • 需要从简单任务（如 Sorting Packages）开始课程学习
  • 建议先训练 K=64 的短任务模型，再在连续任务上微调
  • 推理时加 Temporal Ensemble（4x），减少跨 chunk 的动作跳变

四、训练阶段清单（按优先级）


阶段一：数据准备（关键！）


优先级：最高，数据决定上限


# 1. 数据清洗
# - 去除动作异常值（关节限位外、力矩突变）
# - 去除视觉卡顿帧（连续帧间差异过小/过大）
# - 对齐语言指令和动作（指令描述的动作和实际轨迹匹配）

# 2. 数据归一化
# - 动作：z-score 归一化到 N(0,1)
# - 观测：min-max 归一化到 [0,1]
# - 保存归一化参数用于推理时反归一化

# 3. 课程数据组织
# - 按任务长度分组
# - 按难度分级（collision_risk, trajectory_length）

阶段二：训练配置（按顺序调）


调参顺序，不要打乱


① CFG w → ② Loss 类型 → ③ Chunk Size → ④ 学习率 → ⑤ 其他

① CFG w（影响最大）

先用默认值 1.0
在验证集上扫 [0.5, 0.75, 1.0, 1.25, 1.5]
选验证成功率最高的

② Loss 类型（影响第二大）

默认用 Huber delta=1.0
如果精细操作 → 切换到 Smooth-L1
如果对抗性环境 → 切换到 Huber delta=5.0

③ Chunk Size（影响架构选择）

< 3 秒任务 → K=16
3~6 秒任务 → K=32~64
> 6 秒任务 → K=64~128 + DiT

④ 学习率（影响收敛）

VLM 冻结时：lr=1e-4, head_lr=3e-4
VLM 微调时：lr=3e-5, head_lr=1e-4

⑤ 其他（细节优化）

EMA decay: 0.9999（几乎必开）
梯度裁剪: 1.0（稳定训练）
Batch size: 越大越好（受显存限制）

目标：20ms 内完成感知+推理+控制指令

    └── < 1ms ✅✅

六、常见失败模式与急救方案


6.1 训练崩溃


症状原因急救方案
Loss = NaN梯度爆炸降低学习率 2x，启用梯度裁剪
Loss 突然跳升学习率太大使用 LR warmup（1000步）
Loss 不下降损失函数设计错误检查动作归一化是否正确
EMA loss 上升EMA 衰减率太高降低 decay 到 0.9995

6.2 推理质量差


症状原因急救方案
动作抖动大DDIM 步数太少增加到 15~20 步
指令不遵循CFG w 太低提高到 1.25~1.5
动作不连贯Chunk 内动作独立换 DiT backbone
泛化差VLM 太强/太弱调 VLM freeze 策略
夹爪乱动夹爪动作 loss 权重低提高夹爪维度权重

6.3 推理速度慢


症状原因急救方案
推理 > 50msDDIM 步数太多降到 10 步，用 DPM-Solver
推理 > 30ms视觉编码慢TensorRT FP16 优化
推理 > 20ms模型太大量化到 INT8 或减小模型

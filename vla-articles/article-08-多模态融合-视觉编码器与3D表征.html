一、视觉编码器：主流方案对比


1.1 四种主流视觉编码器总览


编码器参数量特点适合场景代表工作
SigLIP300M~2B对比学习，语义强开放词汇理解GR00T-N1
DINOv2300M~1B自监督，局部特征好精细操作、位姿估计OpenVLA
CLIP63M~1B图文对比，泛化强zero-shot 场景早期 VLA
InternVL2B~20B文档级理解复杂指令GO-1 (2B)
EVA-021BViT 改进高分辨率多种 VLA

1.2 SigLIP：语义理解优先


SigLIP 是 Google 的 Sigmoid Loss CLIP 变体，用 Pairwise Sigmoid Loss 替代 InfoNCE：


$$\mathcal{L} = -\sum_i \log \frac{1}{1 + \exp(-y_i \cdot (W v_i + b))}$$


SigLIP 的优势：


  • 语义分类更强：不需要 batch 内负样本，不像 CLIP 那样依赖 batch 大小
  • 多语言友好：文本-图像对齐更鲁棒
  • 训练稳定：sigmoid loss 比 softmax 更稳定

    • GR00T-N1 使用 SigLIP，因为它的优势在于语言指令的语义理解。


    1.3 DINOv2：局部特征优先


    DINOv2 是 Meta 的自监督 ViT，核心是 Self-Supervised + Local Features：


    DINOv2 特征包含：
├── 全局 CLS token：图像级别表征（用于分类/检索）
├── Patch tokens：局部特征（用于精细操作）
└── Multi-scale features：底层纹理 + 高层语义

    为什么 DINOv2 适合精细操作：

    • 局部特征对物体边缘、关节位置敏感
    • 对光照变化鲁棒（自监督学到的是底层视觉结构）
    • 不依赖语言，可以泛化到未见过的新物体

    1.4InternVL：大规模多模态融合


    InternVL 是上海人工智能实验室的大规模 VLM，GO-1 使用 InternVL 2.5-2B 作为 backbone：


    核心架构：


    图像 → ViT（冻结）→ 视觉特征
                         ↓
文本 → LLM（解冻）→ 语言特征
                         ↓
               动态模态交互（Attention）
                         ↓
              全局多模态表征 → 动作预测

    InternVL 的优势：


  • 原生支持高分辨率（1344×1344），比 SigLIP 的 224×224 能看到更多细节
  • 文档级理解：能读懂标签、说明书、手写文字
  • 强大的中文支持：对中国比赛场景更友好


    • 二、视觉编码器的选择决策树


    任务需要强语义理解（"把那个红色的盒子..."）？
    ├── 是 → SigLIP / InternVL
    └── 否（需要精细操作，如抓取、装配）
          ├── 是 → DINOv2
          └── 否（需要 3D 理解）
                └── 深度传感器 → DepthAnything + 点云 / NeRF

    比赛推荐：


    任务类型推荐视觉编码器理由
    家庭服务机器人InternVL 2B中文 + 复杂指令
    工业精密装配DINOv2 + 深度精细操作需要局部特征
    开放词汇抓取SigLIP语义理解最重要
    通用 VLA（无特殊偏好）SigLIP平衡最好，GR00T-N1 验证过


    三、DepthAnything：深度估计的新基线


    3.1 为什么需要深度信息


    2D RGB 的问题：无法知道物体的真实距离。


    RGB 图像：杯子在图像左侧
深度图像：杯子距离机器人 0.3 米
         ↓
         → 机器人可以判断：伸手 0.3 米就能碰到

    没有深度信息的 VLA 在遮挡判断、精确抓取上会吃亏。


    3.2 DepthAnything 的核心思想


    DepthAnything（VLA 有深度版）是一个基础模型，输入单目 RGB 图像，输出深度图：


    # DepthAnything 用法示例
from depth_anything import DepthAnything

model = DepthAnything(encoder='vitl', features=256)
depth_map = model.infer(image_rgb)  # [H, W]，单位米

    DepthAnything 的优势：


    对比项传统深度估计DepthAnything
    泛化能力差，只能泛化到相似场景强，像 CLIP 一样泛化
    精度一般与 MiDaS 相当甚至更好
    速度慢快（优化过）
    零样本不支持支持

    3.3 深度信息注入 VLM 的方式


    方案一：深度图拼接（最简单）


    # RGB [3, 224, 224] + Depth [1, 224, 224] → [4, 224, 224]
depth_normalized = normalize_depth(depth_map)
image_4channel = torch.cat([rgb, depth_normalized], dim=0)

# 需要修改 ViT 的 stem 接受 4 通道输入
vit_stem = nn.Conv2d(4, embed_dim, kernel_size=16, stride=16)

    方案二：双路编码（推荐，更精细）


    class DualVisionEncoder(nn.Module):
    """
    RGB 和 Depth 分别编码，再融合
    """
    def __init__(self):
        self.rgb_encoder = SigLIP_ViT()
        self.depth_encoder = DINOv2_ViT()  # DINOv2 对局部特征更好
        
        # 融合
        self.fusion = nn.MultiheadAttention(embed_dim=1024, num_heads=16)
    
    def forward(self, rgb, depth):
        rgb_feat = self.rgb_encoder(rgb)      # [B, seq, D]
        depth_feat = self.depth_encoder(depth) # [B, seq, D]
        
        # Cross-attention 融合
        fused, _ = self.fusion(rgb_feat, depth_feat, depth_feat)
        return fused


    四、3D 表征：机器人操作的最佳视觉形式


    4.1 为什么需要 3D 表征


    2D 图像的问题在于缺乏物理维度：

    • 不知道物体大小（一张照片可以是近处小物体，也可以是远处大物体）
    • 不知道物体形状（球体和圆盘在 2D 上看起来一样）
    • 不知道空间关系（前后遮挡无法判断）

    4.2 三种 3D 表征对比


    表征类型维度生成难度计算量适合任务
    点云3D XYZ中等（深度相机直接输出）中抓取、避障
    体素3D 网格难高场景重建
    NeRF神经辐射场难（需要多视角）极高仿真数据生成
    3D Gaussian3D Gaussians中等高仿真数据生成
    BEV（鸟瞰图）2D + 高度低低导航

    4.3 点云编码器：PointNet++ vs PointNeXt


    import torch
import pointnet2_ops

class PointCloudEncoder(nn.Module):
    """
    点云编码器：PointNet++ 风格
    """
    def __init__(self, out_dim=512):
        super().__init__()
        # SA = Set Abstraction（降采样 + 局部特征）
        self.sa1 = pointnet2_ops.PointnetSAModule(
            npoint=512, radius=0.1, nsample=32, 
            mlp=[3, 64, 64, 128])  # 输入 3D XYZ
        self.sa2 = pointnet2_ops.PointnetSAModule(
            npoint=128, radius=0.2, nsample=32,
            mlp=[128, 128, 128, 256])
        self.sa3 = pointnet2_ops.PointnetSAModule(
            npoint=None, radius=None, nsample=16,  # 全局
            mlp=[256, 256, 512, out_dim])
    
    def forward(self, xyz):
        """
        Args:
            xyz: [B, N, 3] 原始点云
        """
        l1_feat, l1_xyz = self.sa1(xyz)
        l2_feat, l2_xyz = self.sa2(l1_feat, l1_xyz)
        global_feat = self.sa3(l2_feat, l2_xyz)
        return global_feat  # [B, out_dim]

    4.4 VoxNet：简单有效的 3D 卷积


    如果不想用点云，可以用 Voxelization + 3D CNN：


    class VoxNet(nn.Module):
    """
    体素编码器：3D CNN 处理离散化的体素网格
    """
    def __init__(self, voxel_dim=32, out_dim=512):
        super().__init__()
        # [V, V, V] 体素网格
        self.conv1 = nn.Conv3d(1, 16, kernel_size=5, stride=2)  # [V/2]
        self.conv2 = nn.Conv3d(16, 32, kernel_size=3, stride=2)  # [V/4]
        self.conv3 = nn.Conv3d(32, 64, kernel_size=3, stride=2)  # [V/8]
        
        self.fc = nn.Linear(64 * (voxel_dim//8)**3, out_dim)
    
    def forward(self, voxel):
        x = torch.relu(self.conv1(voxel))
        x = torch.relu(self.conv2(x))
        x = torch.relu(self.conv3(x))
        x = x.flatten(1)
        return self.fc(x)


    五、无标注视频数据的利用


    5.1 问题：为什么需要无标注视频


    有标注的机器人数据（action-labeled demos）成本极高。互联网上有大量机器人操作视频，这些视频：

    • 没有精确的 action label
    • 但包含丰富的动作意图信息

    GO-1 的核心洞察：用 Latent Action 可以从无标注视频中学习动作先验。


    5.2 LAPA：Language-Augmented Pretraining Approach


    LAPA（GO-1 使用的预训练方法）的核心思想：


    无标注视频
    ↓
视觉特征（VLM）
    ↓
用视频的帧间差异作为隐式动作信号（不需要精确 action label）
    ↓
训练 Latent Action 表征

    class LAPAPretraining(nn.Module):
    """
    LAPA 预训练：从无标注视频学习动作先验
    
    核心：用连续帧的差异作为"伪动作"训练 latent action
    """
    def __init__(self, vlm, latent_action_dim=256):
        super().__init__()
        self.vlm = vlm  # 冻结的 VLM
        self.latent_encoder = LatentActionEncoder(latent_action_dim)
        self.latent_decoder = LatentActionDecoder()
        
        # 伪动作生成：从连续帧的差异提取
        self.pseudo_action_extractor = PseudoActionExtractor()
    
    def forward(self, video_frames):
        """
        Args:
            video_frames: [B, T, 3, H, W] 视频帧序列
        """
        B, T = video_frames.shape[:2]
        
        # 提取帧级视觉特征
        vlm_feats = []
        for t in range(T):
            feat = self.vlm(video_frames[:, t])  # [B, D]
            vlm_feats.append(feat)
        vlm_feats = torch.stack(vlm_feats, dim=1)  # [B, T, D]
        
        # 伪动作：从帧间差异提取
        pseudo_actions = self.pseudo_action_extractor(vlm_feats)
        
        # Latent action 学习：特征 → 隐动作 → 重建伪动作
        latent = self.latent_encoder(vlm_feats[:, :-1])  # [B, T-1, latent]
        reconstructed = self.latent_decoder(latent)
        
        # 对比损失：相同视频的 latent 接近，不同视频的 latent 远离
        contrastive_loss = self.contrastive_loss(latent, pseudo_actions)
        recon_loss = F.mse_loss(reconstructed, pseudo_actions)
        
        return recon_loss + 0.1 * contrastive_loss

    六、视频预测作为辅助任务


    6.1 核心思想


    让模型同时学习两个任务：

  • 主要任务：从 obs 预测 action
  • 辅助任务：从 obs 预测下一帧（视频预测）

    • 视频预测任务强迫模型理解物理世界的因果结构：

    • 物体受力会移动
    • 夹爪合上物体会被抓取
    • 手松开物体就会掉落

    6.2 实现方式


    class AuxiliaryVideoPrediction(nn.Module):
    """
    视频预测辅助任务：提升模型的物理理解能力
    """
    def __init__(self, vla_model, video_predictor):
        super().__init__()
        self.vla = vla_model
        self.video_predictor = video_predictor  # e.g., Video Diffusion Model
    
    def forward(self, obs, lang, actions):
        # 主任务：预测动作
        pred_actions = self.vla(obs, lang)
        action_loss = F.mse_loss(pred_actions, actions)
        
        # 辅助任务：预测下一帧
        current_frame = obs['image'][:, -1]  # 最新帧
        next_frame_pred = self.video_predictor(
            current_frame, actions[:, 0]  # 用第一个动作预测下一帧
        )
        video_loss = F.mse_loss(next_frame_pred, obs['image'][:, -2])
        
        # 总损失
        total_loss = action_loss + 0.3 * video_loss
        
        return total_loss, {
            'action_loss': action_loss,
            'video_loss': video_loss
        }

    6.3 视频预测的额外好处


    实验发现，加入视频预测辅助任务后：


    能力提升效果
    物理常识模型学会"物体不受力会保持静止"
    长时序一致性视频预测需要理解动作的长期效果
    场景理解对遮挡、物体关系理解更深
    分布外泛化对新场景的物理推断能力更强

    八、本篇要点总结


    知识点关键结论
    SigLIP语义理解最强，适合语言指令丰富的任务
    DINOv2局部特征最好，适合精细操作
    InternVL中文支持好，支持高分辨率，适合复杂指令
    DepthAnything零样本深度估计，显著提升抓取精度
    3D 表征点云适合实时，NeRF/GS 适合离线仿真数据生成
    LAPA从无标注视频学习动作先验，不需要精确 action label
    视频预测辅助任务，提升物理常识和长时序一致性
    双路编码RGB 和 Depth 分别编码再融合，效果优于拼接

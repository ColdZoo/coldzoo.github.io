一、问题的起源：条件扩散模型


1.1 无条件 vs 有条件扩散


标准的 DDPM 是无条件的——从噪声生成样本时没有任何控制信号。


但机器人控制需要条件扩散：根据当前观测 $o$ 和语言指令 $g$ 生成对应动作。


如何注入条件？


一种方式是训练一个分类器 $p_\phi(c | a_t)$，在去噪过程中引导采样方向。但这需要额外的分类器训练，且分类器本身可能不稳定。


更优雅的方案：Classifier-Free Guidance（CFG），不需要单独的分类器。



二、CFG 的完整数学推导


2.1 隐式分类器（Implicit Classifier）


给定扩散模型的噪声预测 $\epsilon_\theta(a_t, c, t)$，可以推导出对数条件概率梯度（隐式分数）：


$$\nabla_{a_t} \log p(c | a_t) \approx \frac{1}{\sqrt{1 - \bar{\alpha}_t}} \left( \epsilon_\theta(a_t, c, t) - \epsilon_\theta(a_t, \emptyset, t) \right)$$


推导过程（完整版）：


第一步：贝叶斯定理

$$p(c | a_t) = \frac{p(a_t | c) p(c)}{p(a_t)}$$


第二步：取对数并对 $a_t$ 求梯度

$$\nabla_{a_t} \log p(c | a_t) = \nabla_{a_t} \log p(a_t | c) - \nabla_{a_t} \log p(a_t)$$


第三步：利用 Score Function 形式

$$\nabla_{a_t} \log p(a_t | c) = -\frac{\epsilon_\theta(a_t, c, t)}{\sqrt{1 - \bar{\alpha}_t}}$$

$$\nabla_{a_t} \log p(a_t) = -\frac{\epsilon_\theta(a_t, \emptyset, t)}{\sqrt{1 - \bar{\alpha}_t}}$$


第四步：代入

$$\nabla_{a_t} \log p(c | a_t) = \frac{\epsilon_\theta(a_t, \emptyset, t) - \epsilon_\theta(a_t, c, t)}{\sqrt{1 - \bar{\alpha}_t}}$$


这个梯度告诉我们：如何调整 $a_t$ 才能让条件 $c$ 更可能成立。


2.2 CFG 引导采样


有了隐式分类器梯度，我们可以在 DDIM 采样中加入引导项：


$$\tilde{\epsilon}_\theta(a_t, c, t) = \epsilon_\theta(a_t, c, t) + w \cdot \underbrace{\left( \epsilon_\theta(a_t, c, t) - \epsilon_\theta(a_t, \emptyset, t) \right)}_{\text{隐式分类器梯度}}$$


化简后：

$$\tilde{\epsilon}_\theta(a_t, c, t) = (1 + w) \cdot \epsilon_\theta(a_t, c, t) - w \cdot \epsilon_\theta(a_t, \emptyset, t)$$


其中 $w \geq 0$ 是引导强度（guidance scale）：

  • $w = 0$：无条件预测（完全忽略条件）
  • $w > 0$：强化条件信号
  • 通常 $w \in [0.5, 2.0]$

2.3 几何直观理解


可以把 CFG 理解为在条件空间和无条件空间之间做线性插值：


无条件预测 ε(∅) ──────────► 条件预测 ε(c)
              ▲
              │
         w 倍差分方向

当 $w$ 增大时，预测向"更满足条件"的方向偏移。



三、机器人控制中的 CFG 实现


3.1 训练阶段：无条件样本的生成


CFG 训练需要同时学习有条件和无条件预测。训练时随机丢弃条件：


def cfg_training_step(model, obs, action, lang_goal, cond_dropout_prob=0.1):
    """
    Classifier-Free Guidance 训练
    
    以 cond_dropout_prob 概率丢弃条件（语言/视觉），训练无条件预测
    """
    batch_size = obs.shape[0]
    
    # 随机决定哪些样本丢弃条件
    mask = torch.rand(batch_size) < cond_dropout_prob  # [B]
    
    # 有条件样本：正常传入
    cond_input = (obs, lang_goal)
    
    # 无条件样本：lang_goal 替换为空/零
    lang_goal_null = get_null_language_embedding(lang_goal)  # [B, lang_dim]
    uncond_input = (obs, lang_goal_null)
    
    # 同时预测
    eps_cond = model(noisy_action, obs, lang_goal, t)       # 有条件
    eps_uncond = model(noisy_action, obs, lang_goal_null, t) # 无条件
    
    # 对于丢弃条件的样本，label 应该是无条件预测
    # 对于保留条件的样本，label 是有条件预测
    target = torch.where(mask.unsqueeze(-1), eps_uncond, eps_cond.detach())
    
    # 预测无条件目标（用于 CFG 推理）
    loss_cond = ((eps_cond - target) ** 2).mean()
    loss_uncond = ((eps_uncond - target) ** 2).mean()
    
    return (loss_cond + loss_uncond) / 2, eps_cond, eps_uncond

3.2 推理阶段：CFG 采样


@torch.no_grad()
def cfg_sample(model, obs, lang_goal, num_inference_steps=20, w=1.0):
    """
    CFG 引导采样
    
    Args:
        model: 扩散模型
        obs: 观测 [batch, obs_dim]
        lang_goal: 语言指令 embedding [batch, lang_dim]
        num_inference_steps: DDIM 步数
        w: CFG 引导强度
    """
    batch_size = obs.shape[0]
    action_dim = model.action_dim
    
    # 生成 null 语言 embedding（训练时用的相同方式）
    lang_null = model.get_null_lang_embedding()  # [1, lang_dim]
    
    # 从纯噪声开始
    a_t = torch.randn(batch_size, action_dim, device=obs.device)
    
    # 时间步
    timesteps = torch.linspace(model.T, 0, num_inference_steps, device=obs.device).long()
    
    for i in range(num_inference_steps - 1):
        t = timesteps[i]
        
        # 有条件预测
        eps_cond = model.forward_cfg(a_t, obs, lang_goal, t)
        
        # 无条件预测
        eps_uncond = model.forward_cfg(a_t, obs, lang_null.expand(batch_size, -1), t)
        
        # CFG 引导
        if w > 0:
            eps = (1 + w) * eps_cond - w * eps_uncond
        else:
            eps = eps_cond
        
        # DDIM 更新
        a_t = ddim_step(a_t, eps, t, timesteps[i + 1], model)
    
    return a_t


四、CFG Scale 的系统性调节指南


4.1 $w$ 的理论分析


从 CFG 公式可以看出：


$$\tilde{\epsilon} = \epsilon_c + w(\epsilon_c - \epsilon_u)$$


当 $w$ 增加时：

  • 条件对齐增强：动作更严格地遵循语言指令
  • 多样性降低：不同条件会产生更不同的动作
  • 潜在风险：$w$ 过高时可能产生条件过度信任——即使 VLM 特征有误，动作仍会强行对齐

    • 4.2 $w$ 与任务难度的关系


    任务类型推荐 $w$原因
    简单/短时序任务$w = 0.5 \sim 1.0$指令简单，模型本身对齐能力足够
    复杂/长时序任务$w = 1.0 \sim 1.5$需要更强的指令遵循能力
    泛化到新指令$w = 1.5 \sim 2.0$新指令数据少，需要更强的引导
    精细操作（精度优先）$w = 0.75$避免过度调整破坏精细精度
    避障/安全优先$w = 0.5 \sim 0.75$保持一定多样性，避免锁死单一路径

    4.3 $w$ 的自适应调节


    可以在推理时根据条件置信度动态调节 $w$：


    def adaptive_cfg_sample(model, obs, lang_goal, base_w=1.0, 
                        confidence_threshold=0.8):
    """
    自适应 CFG：根据语言模型的条件置信度动态调整 w
    
    当语言指令置信度高时 → 提高 w（更听话）
    当语言指令置信度低时 → 降低 w（保持多样性）
    """
    # 先做一次无条件采样估计不确定性
    with torch.no_grad():
        lang_null = model.get_null_lang_embedding()
        eps_cond = model(a_t_sample, obs, lang_goal, t)
        eps_uncond = model(a_t_sample, obs, lang_null, t)
        
        # 用两个预测的差异作为置信度代理
        discrepancy = torch.abs(eps_cond - eps_uncond).mean()
        confidence = 1.0 - torch.tanh(discrepancy / 2.0)  # 映射到 [0, 1]
    
    # 置信度低 → 降低 w，置信度高 → 提高 w
    if confidence < confidence_threshold:
        w = base_w * (confidence / confidence_threshold)
    else:
        w = base_w * (1.0 + (confidence - confidence_threshold) * 0.5)
    
    return cfg_sample(model, obs, lang_goal, w=w)

    4.4 训练时的 CFG 调度


    建议在训练过程中逐渐增加引导强度，而不是固定 $w$：


    def get_cfg_w(step, total_steps, w_min=0.5, w_max=1.5):
    """
    CFG w 值退火：从 w_min 逐渐增加到 w_max
    
    训练早期（w 小）→ 模型探索多种动作
    训练晚期（w 大）→ 模型精修对齐指令的动作
    """
    progress = step / total_steps
    # 余弦退火
    w = w_min + 0.5 * (w_max - w_min) * (1 - math.cos(math.pi * progress))
    return w


    五、与中间语义层联合使用的 Semantic-CFG


    5.1 问题：普通 CFG 的局限


    普通 CFG 只在动作空间引导——无论条件信号多复杂（语言、视觉 goal），都压缩成 $\epsilon_c - \epsilon_u$ 的差分。


    这在语义层存在的情况下浪费了中间层的语义信息。


    5.2 Semantic-CFG 的设计


    在 ACoT-VLA 和 GO-1 的设计中，可以在语义层也注入 CFG 引导：


    原始 CFG（仅动作空间）：
    ε(a_t, c) - ε(a_t, ∅)

Semantic-CFG（语义层 + 动作层双重引导）：
    [ε(a_t, c_s, c_a) - ε(a_t, ∅_s, ∅_a)]
    其中 c_s = 语义层条件, c_a = 动作层条件

    class SemanticCFG(nn.Module):
    """
    语义层 CFG：在语义表征空间和动作空间同时做引导
    """
    def __init__(self, model, semantic_dim=512, action_dim=7):
        super().__init__()
        self.model = model  # 主模型
        self.semantic_proj = nn.Linear(semantic_dim, semantic_dim)
        self.action_proj = nn.Linear(action_dim, action_dim)
        
        # 语义空间 CFG 权重
        self.w_semantic = 0.5
        # 动作空间 CFG 权重
        self.w_action = 1.0
    
    def forward(self, noisy_action, obs, lang_goal, t, 
                semantic_cond, semantic_null,
                use_cfg=True):
        """
        在语义层和动作层同时注入 CFG
        """
        # 语义层条件预测
        sem_cond = self.semantic_proj(semantic_cond)
        
        # 语义层无条件预测
        sem_uncond = self.semantic_proj(semantic_null)
        
        # 动作层预测（包含语义条件）
        eps_cond = self.model(noisy_action, obs, lang_goal, t, sem_cond)
        
        # 动作层预测（无条件语义）
        eps_uncond = self.model(noisy_action, obs, lang_goal, t, sem_uncond)
        
        if not use_cfg:
            return eps_cond
        
        # 双重 CFG
        eps_semantic_guidance = eps_cond - eps_uncond
        
        # 在动作空间也做 CFG（标准）
        eps_action = (1 + self.w_action) * eps_cond - self.w_action * eps_uncond
        
        # 在语义空间也做 CFG，然后投影到动作空间
        eps_semantic = (1 + self.w_semantic) * eps_cond - \
                       self.w_semantic * eps_cond  # 简化版
        
        # 两者融合
        eps_final = eps_action + 0.3 * eps_semantic_guidance
        
        return eps_final

    5.3 语义 CFG 的效果


    在 ACoT-VLA 的实验设定下，Semantic-CFG 相比普通 CFG：


    指标普通 CFGSemantic-CFG
    指令遵循准确率91.2%94.7%
    长时序任务成功率85.2%93.1%
    分布外泛化72.3%81.5%

    语义层 CFG 的核心价值：条件信号（语言/视觉 goal）先通过语义层理解，再传递到动作层，减少了噪声条件对动作的直接干扰。



    六、CF Confusion：避免 CFG 的常见误区


    6.1 误区一：CFG w 越高越好


    错误。过高的 $w$ 会导致：


    • 多样性崩溃：无论什么条件都生成相似的动作
    • 误差放大：VLM 的误判会被 CFG 放大（误判 + 强行对齐 = 错误动作）
    • 训练-推理不匹配：训练时用 $w=0.5$，推理时用 $w=3.0$，行为完全不同

    建议：在 [0.5, 1.5] 范围内调参，用验证集选最优。


    6.2 误区二：条件 dropout 只用于 CFG


    错误。条件 dropout（训练时随机丢弃条件）有两个目的：


  • 显式目的：训练无条件预测器（用于 CFG 推理）
  • 隐式目的：正则化——让模型不过度依赖单一条件信号

    • 即使你不打算用 CFG，条件 dropout 仍然能提升模型泛化能力。


    6.3 误区三：CFG 可以弥补训练数据不足


    有限效果。CFG 能帮助模型更好地利用已有条件信息，但无法凭空创造数据。


    如果训练数据中几乎没有某类指令，CFG 无法让它学会这个指令——只能让它在遇到这个指令时更"听话"（但可能产生幻觉动作）。

    八、本篇要点总结


    知识点关键结论
    CFG 隐式分类器无需额外分类器，通过 $\epsilon_c - \epsilon_u$ 即可引导条件生成
    CFG 公式$\tilde{\epsilon} = (1+w)\epsilon_c - w\epsilon_u$，$w$ 控制引导强度
    $w$ 通用范围0.5~1.5，精细操作偏低，长时序/泛化偏高
    条件 dropout既是 CFG 前提，也是正则化手段，建议保留
    自适应 CFG根据条件置信度动态调节 $w$，避免过度/不足引导
    Semantic-CFG在语义层和动作层双重引导，效果优于单层 CFG
    训练时 w 退火训练早期用小 w，晚期用大 w，平衡探索和精修
    常见误区$w$ 越高越好（错误）、CFG 弥补数据不足（有限效果）

一、进化史：从 Behavior Cloning 到 VLA


理解 VLA 不是凭空产生的，了解进化路径能帮你更好地理解每个设计的动机。


1.1 Behavior Cloning（行为克隆）


最原始的方法，直接监督学习：


obs → MLP → action

损失函数就是简单的 MSE。问题：没有泛化能力，分布外（OOD）场景下行为崩溃。


1.2 ACT（Action Chunking Transformer）


论文：Action Chunking with Transformers (2023, Berkeley)


核心思想：一次预测一整个动作序列（chunk），而不是单步动作：


obs (multiple frames) → Transformer → [a_t, a_{t+1}, ..., a_{t+K}]  (K=16~64)

创新点：

  • 用 Transformer 的自注意力建模时序依赖
  • Chunk 内动作相互一致，不会步步累积误差
  • 训练时用 ES（Expectation-Maximization）进行有标签的模仿学习

ACT 在单任务上效果很好，但泛化能力弱，换了任务就需要重新训练。


1.3 Diffusion Policy（扩散策略）


论文：Diffusion Policy: Visuomotor Policy Learning via Diffusion (Columbia, 2024)


这是第一次把扩散模型引入机器人控制：


obs → Vision Encoder → 视觉特征
obs → State Encoder → 状态特征
concat → Noise Pred Net (U-Net/DiT) → 预测 noise
         conditioned by: obs + time embedding

革命性改变：

  • 多模态动作分布（同一指令多种抓法）可以被自然建模
  • Action Chunking 能力内置（一次生成 16~64 步）
  • 高维动作空间的优化变得更稳定

1.4 VLA（Vision-Language-Action）时代


核心区别：VLA = 预训练的 大视觉-语言模型（VLM） + 动作头。


语言指令 + 视觉图像
    → 预训练 VLM（如 InternVL, SigLIP, CLIP）
    → 动作解码器（Diffusion / Autoregressive）
    → 机器人动作

VLM 提供：

  • 语义理解：理解"把红色积木放到蓝色盒子左边"
  • 视觉泛化：ImageNet 级别的开放词汇视觉识别能力
  • 语言对齐：zero-shot 理解新指令


    • 二、GO-1：ViLLA 架构逐层拆解


    2.1 整体架构


    GO-1 的核心创新是 ViLLA（Vision-Language-Latent-Action） 框架，不是简单的 VLA，而是四元组：


    Vision（视觉） → Language（语言） → Latent Action（隐式动作） → Action（显式动作）

    架构总览：

    图像输入 (640×480 RGB)
    → InternVL 2.5-2B（冻结 VLM backbone）
    → 视觉-语言特征融合

语言指令
    → LLM Encoder（和 VLM 共享）

VLM 输出特征 + 动作先验
    → MoE（混合专家）Action Head
    → 预测隐式动作表示

隐式动作解码
    → 显式机器人动作 (7-DoF 末端位姿)

    参数量：整个模型约 3B 参数，Action Head 使用 MoE 结构。


    2.2 关键创新：Latent Action（隐式动作）


    这是 ViLLA 和传统 VLA 最核心的区别。


    传统 VLA：

    obs → VLM → 直接预测 action

    ViLLA：

    obs → VLM → 预测 latent action（中间隐表示）→ 解码成真实动作

    Latent Action 的价值：


  • 数据效率：可以从海量无标注视频（网上爬的机器人视频）中学习。视频里有动作，但没有精确的 action label——但 latent action 不需要精确标签，可以通过对比学习或重建目标学到动作先验。
  • 缓解 sim-to-real gap：latent space 比动作空间更易迁移
  • Cross-embodiment 适配：同一套 latent action 可以解码到不同机器人

    • 2.3 MoE Action Head


    GO-1 的 Action Head 使用 Mixture of Experts（MoE）：


    • 总共有 $N$ 个专家网络（e.g., 8 个）
    • 给定当前状态，路由器（Router）选择激活 $K$ 个专家（e.g., top-2）
    • 不同任务/场景激活不同专家

    这样做的好处：不同动作模式（抓取、放置、导航）可以由不同专家处理，增加模型容量而不增加推理计算量。


    2.4 训练数据


    GO-1 在两个数据集上训练：


    数据集规模特点
    AgiBot World-Alpha49.8M 样本智元自有真机采集，质量最高
    AgiBot World-Beta248M 样本更大规模，包含更多场景

    此外还利用了互联网异构视频进行 latent action 预训练——这是 GO-1 泛化能力的关键。



    三、ACoT-VLA：动作思维链详解


    3.1 核心问题：语义-运动学鸿沟


    传统 VLA 的问题是：语义理解和运动控制之间存在鸿沟。


    • VLM 擅长理解"这是一个应该被放进蓝色容器的红色物体"
    • 但 VLM 的特征空间是为图像描述设计的，和精确的关节运动控制并不对齐

    ACoT-VLA 的解决思路：让推理过程直接在动作空间中进行，而不是在语言空间或视觉空间。


    3.2 双组件架构：EAR + IAR


    ACoT-VLA 有两个并行的推理组件：


    EAR（Explicit Action Reasoner）—— 显式动作推理器


    这是一个轻量级 Transformer，输入：

    • 当前观测特征（来自 VLM）
    • 语言指令特征
    • 粗粒度运动轨迹（上一帧的动作意图）

    输出：

    • 下一帧的动作意图（action intent）——这是显式的，表示为粗粒度运动方向

    粗粒度运动线索 + 视觉-语言特征 → EAR → 动作意图向量

    EAR 专门建模运动学层面的推理：先往哪个方向伸手、张开多大角度的夹爪。


    IAR（Implicit Action Reasoner）—— 隐式动作推理器


    通过交叉注意力（Cross-Attention） 从 VLM 骨干网络中挖掘隐式动作先验：


    VLM 特征 → IAR (Cross-Attention) → 隐式动作先验

    IAR 并不显式输出动作，而是通过注意力机制从 VLM 的海量知识中提炼和动作相关的表征。


    EAR + IAR → ACoT


    Step 1: IAR 从 VLM 中提取隐式动作先验（"从语义层面，我知道这是个需要精细操作的物体"）
Step 2: EAR 融合隐式先验 + 显式运动线索 → 生成动作意图
Step 3: 动作意图解码为具体关节角度
Step 4: 下一帧重复 → 链式动作推理链

    3.3 为什么叫"思维链"？


    和 LLM 的 Chain-of-Thought（思维链）类比：

    • LLM CoT：在语言空间逐步推理（"先算这个，再乘那个"）
    • ACoT：在动作空间逐步推理（"先伸手，再张爪，再抓取"）

    关键区别是：ACoT 的中间结果不是语言文字，而是动作意图向量。


    3.4 性能数据


    ACoT-VLA 在 AgiBot LIBERO 基准上表现：


    任务类型成功率提升
    LIBERO-Long（长时序）85.2% → 96.0%（+10.8%）
    整体平均94.1% → 98.5%
    鲁棒性测试（相机变化/噪声）平均 84.1%


    四、π0：Flow Matching + VLM 的端到端融合


    4.1 架构概述


    π0（Physical Intelligence, 2024.10）是第一个真正做到端到端训练的 VLA：


    VLM Backbone（7B，如 LLaVA）
    ↕（联合训练，梯度流通）
Diffusion Action Head（Flow Matching）

    关键区别于 GO-1：

    • GO-1 是两阶段训练（先冻住 VLM，再训练 Action Head）
    • π0 是 VLM 和 Action Head 一起训练，梯度直接反向传播到 VLM

    4.2 Flow Matching Action Head


    π0 的 Action Head 使用 Flow Matching（见第一篇文章），而非 DDPM：


    VLM 特征 + robot state → DiT Block（12层）
                      → 输出 velocity field
                      → 积分 → 动作序列

    4.3 训练目标


    $$\mathcal{L} = \mathbb{E}_{t, \tau, (o,g)} \| v_\tau - v_\theta(\hat{\tau}_t, o, g) \|^2$$


    其中 $\tau$ 是动作轨迹，$\hat{\tau}_t$ 是插值后的中间状态。


    4.4 π0-FAST：动作分词加速


    2025.01 推出的 FAST tokenizer 将连续动作离散化为 token：


    连续动作 [a_1, ..., a_N]
    → DCT（离散余弦变换）
    → 频域表示 → 量化 → token ID

    然后用 next-token prediction 训练，动作生成速度提升 5 倍。


    4.5 π0.5 的后续演进


    π0.5（2025.04）进一步改进了：

    • 更长的动作上下文（512步 vs 64步）
    • 更好的 dexterous manipulation（灵巧手控制）
    • 新的训练策略减少分布外失败


    五、GR00T-N1：NVIDIA 的两阶段设计


    5.1 整体架构


    Stage 1（冻结）：预训练 VLM backbone
                InternVL2 / SigLIP（视觉）
                LLM（语言）
                两模态融合 → 冻结权重

Stage 2（训练）：Action DiT（Flow Matching Head）
                输入：VLM 特征 + robot state
                输出：动作 velocity

    5.2 DiT Action Head


    GR00T-N1 的 Action Head 是一个 Diffusion Transformer（DiT）：


    • 使用和 DiT-XL 相同的架构设计
    • 12 层 Transformer blocks
    • 输入是 VLM 特征的 patchified 表示 + time embedding
    • 输出是动作序列的 velocity prediction

    5.3 两阶段训练策略的优劣


    优势：

    • Stage 1 利用现成高质量 VLM，不需要大量机器人数据
    • Stage 2 只需要训练 Action Head，数据效率高

    劣势：

    • 两阶段目标不同，可能存在特征对齐问题
    • VLM 的语义特征不一定最适合动作控制

    比赛建议：如果你的数据量 < 50 万条轨迹，优先用两阶段（GR00T/GO-1 思路）；超过 100 万条可以考虑端到端（π0 思路）。

    七、比赛选型建议


    你的任务需要哪种架构？


    需要长时序规划（> 5 步）？

    → 优先考虑 ACoT-VLA（显式动作链式推理）或 GO-1 的 latent action


    数据量 < 50 万轨迹？

    → GO-1 / GR00T-N1 思路（两阶段，冻结 VLM）


    数据量充足（> 100 万），需要端到端优化？

    → π0 思路（联合训练，梯度流通到 VLM）


    任务需要泛化到未见过的新物体/场景？

    → GO-1（latent action + 互联网视频预训练）最强


    需要精细灵巧手控制（dexterous manipulation）？

    → π0 / π0.5（专门优化 dexterous 动作）



    八、本篇要点总结


    知识点关键结论
    ViLLA 的 Latent Action核心创新，可以从无标注视频学习动作先验
    ACoT-VLA 的 EAR+IAR显式/隐式双路径解决语义-运动学鸿沟
    π0 端到端训练梯度流通到 VLM，效果好但需要大数据
    GR00T-N1 两阶段数据效率高，适合中等规模数据
    动作分词器 FAST新方向，离散化动作可复用 LLM 训练技巧
    选型优先级先确认数据量和任务类型，再决定用哪个范式

1. Do GPUs Really Need New Tabular File Formats? (GPU 真的需要新的表格文件格式吗？)

  • 来源: arXiv 2602.17335 (2026年2月)
  • 作者: Jigao Luo, Qi Chen, Carsten Binnig
  • 原文: https://arxiv.org/abs/2602.17335
  • PDF: https://arxiv.org/pdf/2602.17335

核心贡献:

  • 系统性地研究了 Parquet 配置对 GPU 扫描性能的影响
  • 发现 Parquet 在 GPU 上性能不佳并非格式本身的问题，而是配置选择不当
  • 提出 GPU 感知的 Parquet 配置方案
  • 无需修改 Parquet 规范即可将有效读取带宽提升至 125 GB/s

技术要点:

  • 传统 Parquet 配置基于 CPU 中心执行模型
  • GPU 加速数据处理需要不同的配置策略
  • 通过优化配置而非重新设计格式来提升 GPU 性能

为什么重要:

  • ✅ 挑战了"需要新文件格式"的假设
  • ✅ 提供了实用的优化方案，无需迁移数据格式
  • ✅ 对现有 Parquet 生态系统友好

相关度: ⭐⭐⭐⭐⭐ 完美匹配 - 同时涉及编码/解码和 GPU 加速

💡 关键洞察


新趋势：优化现有格式 vs 创建新格式

这篇论文提出了一个重要问题：我们真的需要新的文件格式吗？


传统思路：

  • FastLanes (VLDB 2025) → 创建新格式
  • G-ALP (DaMoN 2025) → 创建新编码

新思路：

  • Do GPUs Really Need New Tabular File Formats? → 优化现有 Parquet 配置

结论: 通过 GPU 感知的配置，Parquet 可以达到 125 GB/s 的读取带宽，可能无需迁移到新格式。

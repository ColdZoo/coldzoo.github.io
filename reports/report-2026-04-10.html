🔥 Highlighted Papers


1. SonicDB S6: A Storage-Efficient Verkle Trie for High-Throughput Blockchains

  • Authors: Luigi Crisci, Lorenz Schuler, Herbert Jordan, Bernhard Scholz
  • Source: arXiv:2604.06579, April 8, 2026
  • Category: Data Encoding/Storage Efficiency

Key Contributions:

  • Occupancy-aware node specializations: O(kn²) dynamic programming algorithm for optimal node structure selection
  • Delta node mechanism: Records only changed slots, reducing archive storage by 95%
  • Aggressive storage optimization using Sonic blockchain's non-forking property
  • First production-grade Rust Verkle tree database for 300ms block time blockchains

Performance Improvements:

  • 98% reduction in live storage
  • 95% reduction in archive storage
  • 2.85x higher throughput vs Geth Verkle baseline while maintaining production performance

Link: https://arxiv.org/abs/2604.06579



2. LASER: A Data-Centric Method for Low-Cost and Efficient SQL Rewriting based on SQL-GRPO

  • Authors: Jiahui Li, Tongwang Wu, Yuren Mao, Rong Kang, Tieying Zhang, Yunjun Gao
  • Source: arXiv:2604.06804, April 8, 2026
  • Category: Query Optimization

Key Contributions:

  • SQL-MCTS: Large-scale complex slow query corpus using Monte Carlo Tree Search-based hybrid expansion
  • SQL-GRPO: Specialized alignment strategy derived from Group Relative Policy Optimization
  • Anchored Group Advantage for optimized advantage estimation
  • Complexity-Adaptive Dynamic Rollout for efficient exploration budget allocation
  • First data-centric approach empowering Small Language Models (SLMs) for SQL optimization

Performance Improvements:

  • Significantly outperforms rule-based systems and LLMs in execution efficiency
  • Strong zero-shot transfer capability with minimal overhead

Link: https://arxiv.org/abs/2604.06804



3. CIDER: Boosting Memory-Disaggregated Key-Value Stores with Pessimistic Synchronization

  • Authors: Yuxuan Du, Xuchuan Luo, Xin Wang, Yangfan Zhou, Jiacheng Shen
  • Source: arXiv:2604.03007, April 3, 2026 (Accepted by VLDB'26)
  • Category: Distributed Systems, Storage

Key Contributions:

  • Identifies root cause of I/O redundancy: mismatch between optimistic synchronization and high-concurrency DM workloads
  • Paradigm shift from optimistic to pessimistic synchronization for memory-disaggregated KV stores
  • Global write-combining technique to reduce cross-node redundant I/O
  • Contention-aware synchronization scheme for low-contention scenarios

Performance Improvements:

  • Up to 6.6x throughput improvement vs state-of-the-art memory-disaggregated KV stores on YCSB benchmark

Link: https://arxiv.org/abs/2604.03007



4. AV-SQL: Decomposing Complex Text-to-SQL Queries with Agentic Views

  • Authors: Minh Tam Pham, Trinh Pham, Tong Chen, Hongzhi Yin, Quoc Viet Hung Nguyen, Thanh Tam Nguyen
  • Source: arXiv:2604.07041, April 8, 2026
  • Category: Query Processing, Text-to-SQL

Key Contributions:

  • Agentic Views: LLM agent-generated Common Table Expressions (CTEs) encapsulating intermediate query logic
  • Three-phase pipeline:
  • Rewriter agent: Compresses and clarifies input queries
  • View generator agent: Processes schema chunks to generate views
  • Planner/Generator/Revisor agents: Collaborate to synthesize final SQL
    • Addresses context window limits and schema linking errors in large schemas

    Performance Improvements:

    • 70.38% execution accuracy on Spider 2.0 (state-of-the-art)
    • Spider: 85.59%, BIRD: 72.16%, KaggleDBQA: 63.78%

    Link: https://arxiv.org/abs/2604.07041

🏷️ 数据编码/解码


1. FastLanes 文件格式

  • 会议: VLDB 2025
  • 作者: Azim Afroozeh, Peter Boncz (CWI Amsterdam)
  • 链接: PDF | GitHub

核心贡献:

  • 面向 SIMD/GPU 数据并行执行的新型开源大数据文件格式
  • 灵活的表达式编码机制，支持轻量级、全数据并行编码
  • 级联压缩技术提升压缩比
  • 目标: 解码吞吐量超过 100 亿整数/秒
  • 采用轻量级编码替代通用压缩(如 Snappy)

相关度: ⭐⭐⭐⭐⭐ 高 - 直接针对数据编码/解码与 GPU 加速的结合



🏷️ GPU 加速


2. Vortex: 突破 GPU 加速大规模数据分析的内存容量限制

  • 会议: VLDB 2025
  • 作者: Yichao Yuan, Advait Iyer, Lin Ma, Nishil Talati
  • arXiv: 2502.09541

核心贡献:

  • 针对超出 GPU 内存容量的数据分析工作负载的 GPU 加速框架
  • 优化的 I/O 原语，充分利用多 GPU 系统中的所有 PCIe 链路
  • 新颖的编程模型，将 GPU 内核开发与 I/O 调度分离
  • 零拷贝内存访问实现延迟物化
  • 性能: 相比 Proteus (GPU 基线) 提升 5.7 倍，相比 DuckDB (CPU) 价格性能提升 2.5 倍

相关度: ⭐⭐⭐⭐⭐ 高 - 核心 GPU 数据库加速研究

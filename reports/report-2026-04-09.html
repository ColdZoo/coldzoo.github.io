🔥 Highlighted Papers


1. GPU-RMQ: Accelerating Range Minimum Queries on Modern GPUs

  • Authors: Lara Kreis, Justus Henneberg, Valentin Henkys, Felix Schuhknecht, Bertil Schmidt
  • Source: arXiv:2604.01811, April 2, 2026
  • Category: GPU Acceleration

Key Contributions:

  • Proposes GPU-RMQ using a hierarchical approach with parallel index construction
  • Hybrid design combining ray tracing cores with CUDA cores for query processing
  • Optimized parallel scan operations processing only relevant parts of the hierarchy

Performance Improvements:

  • 8x faster than LCA (GPU)
  • 17x faster than RTXRMQ (GPU)
  • 4800x faster than optimized CPU methods
  • Index construction up to 2 orders of magnitude faster
  • Handles arrays ≥2^29 elements without exceeding RTX 4090 memory

Link: https://arxiv.org/abs/2604.01811



2. ZipServ: Fast and Memory-Efficient LLM Inference with Hardware-Aware Lossless Compression

  • Authors: Ruibo Fan, Xiangrui Yu, Xinglin Pan, Zeyu Li, Weile Luo, Qiang Wang, Wei Wang, Xiaowen Chu
  • Source: arXiv:2603.17435, March 18, 2026 (ASPLOS'26 Accepted)
  • Category: Data Encoding/Decoding, GPU Acceleration

Key Contributions:

  • Tensor-Core-Aware Triple Bitmap Encoding (TCA-TBE) - fixed-length format for parallel decoding
  • ZipGEMM kernel fusing decompression with GEMM operations
  • "Load compressed, compute decompressed" design eliminating intermediate buffers

Performance Improvements:

  • Model size reduction up to 30%
  • Kernel-level speedup up to 2.21x vs NVIDIA cuBLAS
  • End-to-end inference speedup 1.22x vs vLLM
  • First lossless compression system for LLM inference on GPU providing both storage savings and speedup

Link: https://arxiv.org/abs/2603.17435



3. GPU Acceleration of SQL Analytics on Compressed Data

  • Authors: Zezhou Huang, Krystian Sakowski, Hans Lehnert, Wei Cui, Carlo Curino, Matteo Interlandi, Marius Dumitru, Rathijit Sen
  • Source: arXiv:2506.10092, June 2025 (revised September 2025)
  • Category: GPU Acceleration, Data Encoding/Decoding

Key Contributions:

  • Direct SQL query execution on lightweight compressed data (RLE, index encoding, bit-width reductions, dictionary encoding)
  • Multi-RLE column processing without decompression
  • Heterogeneous column encoding support
  • Cross-device portability using PyTorch tensor operations

Performance Improvements:

  • Order of magnitude (10x+) speedup over commercial CPU analytics systems
  • Works on production datasets exceeding GPU HBM capacity
  • Complements existing partitioning and multi-GPU approaches

Link: https://arxiv.org/abs/2506.10092

5. Unified and Efficient Approach for Multi-Vector Similarity Search

  • Authors: Binhan Yang, Yuxiang Zeng, Hengxin Zhang, Zhuanglin Zheng, Yunzhen Chi, Yongxin Tong, Ke Xu
  • Source: arXiv:2604.02815, April 3, 2026
  • Category: GPU Acceleration (applicable)

Key Contributions:

  • MV-HNSW: First native hierarchical graph index for multi-vector data
  • Novel edge weight function satisfying symmetry, cardinality robustness, and query consistency
  • Accelerated multi-vector similarity computation algorithm
  • Enhanced search strategy discovering topologically disconnected but relevant candidates

Performance Improvements:

  • Search latency reduced up to 14.0x vs existing methods
  • Maintains >90% recall on 7 real-world datasets

Link: https://arxiv.org/abs/2604.02815



6. Distance Comparison Operations Are Not Silver Bullets in Vector Similarity Search

  • Authors: Zhuanglin Zheng, Yuxiang Zeng, Chenchen Liu, Yunzhen Chi, Binhan Yang, Yongxin Tong
  • Source: arXiv:2604.02801, April 3, 2026 (ICDE 2026)
  • Category: GPU Acceleration (benchmark study)

Key Contributions:

  • Comprehensive benchmark of 8 DCO algorithms on 10 datasets (up to 100M vectors, 12,288 dimensions)
  • Tested on CPU (with/without SIMD) and GPU
  • Reveals limitations: high dimensionality sensitivity, out-of-distribution query degradation, hardware instability

Key Findings:

  • DCO methods can accelerate index construction and data updates (often overlooked benefit)
  • Current DCO algorithms not ready for production deployment due to unstable performance
  • Sometimes slower than full-dimension scan

Link: https://arxiv.org/abs/2604.02801

7. Making Array-Based Translation Practical for Modern, High-Performance Buffer Management

  • Authors: Xinjing Zhou, Jinming Hu, Andrew Pavlo, Michael Stonebraker
  • Source: arXiv:2604.00423, April 1, 2026
  • Category: Buffer Management (applicable to GPU workloads)

Key Contributions:

  • Calico: Practical DBMS-controlled buffer pool using array-based translation
  • Decouples logical translation from OS page tables
  • Multi-level translation with path caching, hole punching for cold memory reclamation, group prefetching
  • Drop-in replacement for PostgreSQL buffer manager with pgvector integration

Performance Improvements:

  • Vector search: 3.9x in-memory speedup, 6.5x out-of-memory speedup for PostgreSQL
  • Scan-intensive queries: up to 3x speedup
  • Compatible with huge pages and fine-grained page management

Link: https://arxiv.org/abs/2604.00423



8. Optimizing Relational Queries over Array-Valued Data in Columnar Systems

  • Authors: Maroua Zeblah, Etienne Couritas, Sarah Chlyah, Pierre Genevès, Nils Gesbert, Nabil Layaïda
  • Source: arXiv:2604.01967, April 2, 2026
  • Category: Data Encoding, Query Optimization

Key Contributions:

  • A3D-RA: Extended relational algebra supporting array-valued attributes
  • Comprehensive framework for algebraic reasoning and optimization
  • Equivalence-preserving transformation rules capturing pairwise interactions between relational and array operators
  • Polynomial-time plan enumeration strategy with optimality guarantees for non-join operations

Performance Improvements:

  • Consistent performance improvements across three high-performance engines on real workloads
  • Modular, backend-agnostic design deployable as optimization layer on existing systems

Link: https://arxiv.org/abs/2604.01967

9. Cardinality Estimation for High Dimensional Similarity Queries with Adaptive Bucket Probing

  • Authors: Zhonghan Chen, Qintian Guo, Ruiyuan Zhang, Xiaofang Zhou
  • Source: arXiv:2604.04603, April 6, 2026
  • Category: Query Optimization, GPU Acceleration (applicable)

Key Contributions:

  • Lightweight LSH-based framework for cardinality estimation in high-dimensional similarity search
  • Adaptive multi-probe LSH exploring neighboring buckets based on distance thresholds
  • Progressive sampling to reduce distance computations
  • Asymmetric distance computation using product quantization for acceleration
  • Update algorithms for large-scale dynamic data

Performance Improvements:

  • Accurate cardinality estimation with satisfactory online efficiency
  • Applicable to high-dimensional similarity search in production environments

Link: https://arxiv.org/abs/2604.04603

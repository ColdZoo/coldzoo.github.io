3. GPU Acceleration of SQL Analytics on Compressed Data (VLDB 2026)

  • 作者: Jigao Huang, Sebastian Baunsgaard, Maximilian Bandle 等
  • 核心贡献: 在压缩数据上直接运行 SQL 查询，无需解压
  • 性能指标: 数量级性能提升
  • 链接: https://arxiv.org/abs/2506.10092

4. Vortex (VLDB 2025)

  • 作者: Yichao Yuan, Advait Iyer, Lin Ma, Nishil Talati
  • 核心贡献: 超 GPU 内存数据分析框架
  • 性能指标:
  • 比 Proteus 快 5.7 倍
  • 比 DuckDB 价格性能提升 2.5 倍
  • 链接: https://arxiv.org/abs/2502.09541

  • 作者: Bobbi Yogatama, Yifei Yang, Kevin Kristensen 等 (UW-Madison)
  • 核心贡献: GPU 原生 SQL 引擎，DuckDB 后端加速
  • 性能指标:
  • TPC-H 成本效益提升 8.3 倍
  • ClickBench 成本效益提升 7.4 倍
  • 链接: https://arxiv.org/abs/2508.04701

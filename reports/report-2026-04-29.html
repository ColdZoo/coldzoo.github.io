    1. Garfield: GPU多属性范围过滤ANN搜索框架

    属性详情
    标题A GPU-Accelerated Framework for Multi-Attribute Range Filtered Approximate Nearest Neighbor Search
    作者Zhonggen Li, Haoran Yu, Zixuan Xu, Yifan Zhu, Yunjun Gao
    来源arXiv:2604.20121
    提交日期2026年4月22日

    核心贡献:

    • 提出GMG索引：将数据划分为单元格并构建局部图索引，通过恒定数量跨单元格边保证线性存储开销
    • 聚类引导排序策略：重新排序查询相关单元格，实现高效GPU逐单元格遍历
    • 候选点重用机制：跨单元格遍历时重用候选点作为入口点，减少重复计算
    • 核外流水线：单元格导向的动态调度，重叠GPU计算与CPU-GPU数据传输

    性能提升:

    • 🏆 119.8倍 吞吐量提升（相比最先进RFANNS方法）
    • 🏆 4.4倍 索引压缩比
    • 线性存储和索引开销保证


    2. SRDatalog: 最坏情况最优GPU Datalog引擎

    属性详情
    标题Scaling Worst-Case Optimal Datalog to GPUs
    作者Yihao Sun, Kunting Qi, Thomas Gilray, Sidharth Kumar, Kristopher Micinski
    来源arXiv:2604.20073
    提交日期2026年4月22日

    核心贡献:

    • 首个WCOJ-based GPU Datalog引擎：区别于现有基于二元连接的GPU引擎
    • 扁平列式存储 + 两阶段确定性内存分配：避免OOM故障和索引重建开销
    • 负载均衡优化：
    • 根级直方图引导的负载均衡
    • 结构辅助关系拆分
    • 流对齐规则多路复用

    性能提升:

    • 🏆 几何平均21-47倍加速（真实世界程序分析工作负载）
    • 解决SIMT硬件上的键倾斜导致的流处理器负载不平衡问题


    3. 3DPipe: 多面体空间连接GPU框架

    属性详情
    标题3DPipe: A Pipelined GPU Framework for Scalable Generalized Spatial Join over Polyhedral Objects
    作者Lyuheng Yuan, Da Yan, Akhlaque Ahmad, Fusheng Wang
    来源arXiv:2604.19982
    开源代码https://github.com/lyuheng/3dpipe

    核心贡献:

    • 在过滤和精炼阶段均利用GPU并行性
    • 多级剪枝策略实现高效候选集缩减
    • 分块流式处理支持超出GPU内存的数据集

    性能提升:

    • 🏆 9.0倍加速（相比最先进GPU方案TDBase）
    • 出色可扩展性


    4. FPGA B+树批量搜索加速

    属性详情
    标题Efficient Batch Search Algorithm for B+ Tree Index Structures with Level-Wise Traversal on FPGAs
    作者Max Tzschoppe, Martin Wilhelm, Sven Groppe, Thilo Pionteck
    来源arXiv:2604.21117 (cs.AR)
    平台AMD Alveo U250数据中心加速卡

    核心贡献:

    • 层级遍历策略：按层级处理批量搜索键，高效重用树节点
    • 高层综合(HLS)方法：高度灵活可配置的内核设计
    • 支持可变批量大小、自定义节点大小、任意树深度

    性能提升:

    • 🏆 4.9倍加速（单内核FPGA vs 单线程CPU）
    • 🏆 2.1倍加速（4内核FPGA vs 16线程CPU）
    • 减少全局内存访问，提高节点数据重用率

    • QuALITY-hard基准前4名成绩
    • 在多个长文档QA基准上超越传统缩减技术


    6. MCI: 最大团索引用于过滤ANN搜索

    属性详情
    标题MCI: A Maximal Clique Index for Efficient Arbitrary-Filtered Approximate Nearest Neighbor Search
    作者Xiaowei Ye, Rong-Hua Li, Guoren Wang, Kaiwen Xue, Daiyin Wang, Xubin Li
    来源arXiv:2604.22171
    提交日期2026年4月24日

    核心贡献:

    • 最大团覆盖(MCC)：利用高维空间几何传递性，将稠密邻域编码为最大团
    • 局部邻域图几何稠密化：从稀疏NNG构建近似大规模NNG索引
    • 无锁并行构建：保证可扩展性
    • 多种子策略查询：处理谓词诱导的碎片化子图

    性能提升:

    • 🏆 高达一个数量级QPS提升（高召回率条件）
    • 显著更小的存储空间
    • 在范围过滤和关键词过滤任务上保持竞争力

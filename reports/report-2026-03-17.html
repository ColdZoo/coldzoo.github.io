1. 压缩数据上的 SQL 分析 GPU 加速

  • 来源: arXiv (2025) - 可能出现在主要会议
  • 作者: Zezhou Huang, Krystian Sakowski, Hans Lehnert, Wei Cui, Carlo Curino, Matteo Interlandi, Marius Dumitru, Rathijit Sen
  • arXiv: 2506.10092

核心贡献:

  • 直接在轻量级压缩数据上运行 SQL 查询而无需解压的新方法
  • 支持行程编码 (RLE)、索引编码、位宽缩减和字典编码
  • 无需解压的多列 RLE 操作
  • 异构列编码处理
  • 基于 PyTorch 张量操作实现跨设备可移植性
  • 性能: 在生产数据集上比最先进的商业 CPU 分析系统快一个数量级

相关度: ⭐⭐⭐⭐⭐ 完美匹配 - 同时涵盖编码/解码和 GPU 加速



🏷️ GPU 加速


2. GPU 时代的分析处理重构 (Sirius)

  • 来源: arXiv (2025)
  • 作者: Bobbi Yogatama, Yifei Yang, Kevin Kristensen, Devesh Sarda, Abigale Kim, Adrian Cockcroft, Yu Teng, Joshua Patterson, Gregory Kimball, Wes McKinney, Weiwei Gong, Xiangyao Yu
  • arXiv: 2508.04701

核心贡献:

  • Sirius: 开源 GPU 原生 SQL 查询引擎
  • 使用 libcudf 将 GPU 作为主计算引擎
  • 基于 Substrait 与现有数据库无缝集成
  • 为各种数据系统提供即插即用加速
  • 性能:
  • 相比 DuckDB 成本效率提升 8.3 倍 (TPC-H)
  • 相比 DuckDB 成本效率提升 7.4 倍 (ClickBench)
  • 相比 Apache Doris 查询速度提升 12.5 倍

相关度: ⭐⭐⭐⭐⭐ 高 - GPU 原生 SQL 引擎，性能提升显著



🏷️ 数据编码/解码


3. FastLanes 文件格式

  • 会议: VLDB 2025
  • 作者: Azim Afroozeh, Peter Boncz (CWI Amsterdam)
  • 链接: PDF | GitHub

核心贡献:

  • 面向 SIMD/GPU 数据并行执行的新型开源大数据文件格式
  • 比 Parquet 压缩率高约 40%
  • 灵活的表达式编码机制
  • 级联编码提升压缩比
  • 支持多列压缩 (MCC)
  • 目标: 解码吞吐量超过 100 亿整数/秒

相关度: ⭐⭐⭐⭐⭐ 高 - 直接针对编码/解码与 GPU 支持

编码/解码领域 (7篇)


  • FastLanes File Format (VLDB 2025)
    • 面向 SIMD/GPU 的列式文件格式
    • 比 Parquet 压缩率高 40%
    • 解码速度 >100亿整数/秒

  • G-ALP (DaMoN 2025)
    • GPU 轻量级编码重构
    • 针对 GPU 查询处理优化

  • GPU-Based Floating-point Adaptive Lossless Compression (arXiv 2025)
    • 自适应浮点数据压缩框架
    • GPU 原生实现

  • GPU Acceleration of SQL Analytics on Compressed Data (VLDB 2026) ⭐ 双重匹配
    • 压缩数据直接查询
    • 支持 RLE、字典编码、位宽压缩
    • 数量级性能提升

  • ZipFlow (arXiv 2026)
    • 编译器驱动的压缩数据移动
    • 比 DuckDB 快 3.14x

  • Do GPUs Really Need New Tabular File Formats? (arXiv 2026)
    • Parquet GPU 配置优化
    • 达到 125 GB/s 读取带宽

  • GPU-Accelerated Ultra-Lite Encoded Database (期刊 2015)
    • 行列混合存储架构
    • 轻量级编码方案

    GPU 加速领域 (8篇)


  • Vortex (VLDB 2025)
    • 突破 GPU 内存限制的加速框架
    • 比 Proteus 快 5.7x

  • Sirius (arXiv 2025)
    • GPU 原生 SQL 引擎
    • DuckDB 的 GPU 后端
    • TPC-H 8.3x 加速

  • GPU Joins & Aggregations (SIGMOD 2025)
    • GPU 查询处理优化
    • Join 和聚合算子加速

  • Scaling GPU Databases (VLDB 2025)
    • 超内存 GPU 数据处理
    • 多 GPU 扩展

  • GPU Acceleration of SQL Analytics on Compressed Data (VLDB 2026)
    • 压缩数据查询加速
    • 端到端 GPU 执行

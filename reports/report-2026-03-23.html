GPU Acceleration of SQL Analytics on Compressed Data (压缩数据上的 SQL 分析 GPU 加速)

  • 来源: VLDB 2026 (刚被接收！)
  • arXiv: 2506.10092v2
  • 作者: Zezhou Huang, Krystian Sakowski, Hans Lehnert, Wei Cui, Carlo Curino, Matteo Interlandi, Marius Dumitru, Rathijit Sen
  • 原文: https://arxiv.org/abs/2506.10092

核心贡献:

  • ✅ 双重关注领域: 同时覆盖数据编码/解码 + GPU 加速，完美匹配研究兴趣！
  • ✅ 直接查询压缩数据: 无需解压即可在 GPU 上执行 SQL 分析查询
  • ✅ 轻量级编码支持: 运行长度编码 (RLE)、字典编码、位宽压缩等
  • ✅ 混合编码列处理: 支持同一列使用多种编码格式
  • ✅ PyTorch 张量操作: 良好的设备移植性
  • ✅ 数量级性能提升: 相较于先进商用 CPU 分析系统

为什么重要:

  • 🎯 解决 GPU 显存容量有限但数据集很大的核心挑战
  • 🎯 实现端到端 GPU 加速，无需数据解压开销
  • 🎯 生产级数据集验证，具有实际应用价值

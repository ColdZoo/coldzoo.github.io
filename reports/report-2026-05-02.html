🔥 本周重要发现


1. Nacrith: 超越FineZip的神经无损压缩 (2026年2月)

  • arXiv: 2602.19626
  • 作者: Roberto Tacconelli
  • 核心贡献:
  • 使用135M参数transformer模型，比FineZip的Llama3-8B小60倍
  • 在enwik8上达到0.9389 bpb，比FineZip (1.024 bpb) 提升8%
  • 多项创新：32位算术编码、token级N-gram模型、自适应偏差头
  • 性能: 压缩率提升8%，模型体积小60倍，无需微调
  • 链接: https://arxiv.org/abs/2602.19626

2. ZipFlow: GPU压缩数据流编译器框架 (2026年2月)

  • arXiv: 2602.08190
  • 作者: Gwangoo Yeo, Zhiyang Shen, Wei Cui 等
  • 核心贡献:
  • 编译器框架优化GPU加速数据分析中的压缩数据传输
  • 将压缩算法分类为三种并行模式
  • 针对每种模式采用通用调度策略
  • 性能提升:
  • 比nvCOMP快 2.08倍
  • 比DuckDB快 3.14倍 (TPC-H基准)
  • 链接: https://arxiv.org/abs/2602.08190

3. GPU加速压缩数据SQL分析 (2025年6月)

  • arXiv: 2506.10092
  • 作者: Zezhou Huang, Krystian Sakowski, Hans Lehnert 等
  • 核心贡献:
  • 直接在轻量级压缩数据(RLE、索引编码、字典编码)上运行查询
  • 多列RLE操作，无需解压
  • 利用PyTorch张量操作实现跨设备可移植性
  • 性能提升:
  • 比商业CPU分析系统快 10倍
  • 可处理无法放入GPU内存的数据集
  • 链接: https://arxiv.org/abs/2506.10092

🔍 研究趋势分析


1. GPU原生数据库架构成为主流

  • FlashANNS、GRAB-ANNS、gMatch、FliX等论文推动GPU-native架构
  • 异步I/O流水线解决存储-计算瓶颈
  • 计算-内存分离架构兴起

2. 十亿级向量搜索成为标准

  • FlashANNS、VecFlow-Chamfer、Billion-Scale VSS等聚焦超大规模
  • 单GPU处理十亿级向量成为研究热点

3. 学习型压缩 + GPU加速结合

  • L3 (GPU-native learned compression)
  • LICO (SIMD-aware learned inverted index compression)
  • FineZip/Nacrith推动LLM-based压缩

4. 直接在压缩数据上处理

  • ZipFlow、GPU SQL on Compressed Data等
  • 避免解压开销，端到端压缩数据处理

5. 翻转索引范式

  • FliX: 计算到桶映射颠覆传统索引设计
  • 6.5倍延迟降低


📚 重点论文详情


压缩/编码类


Nacrith: Neural Lossless Compression (arXiv 2602.19626)

作者: Roberto Tacconelli
核心创新:
- CDF精度从2^16升级到2^24，消除75%量化开销
- Token级N-gram模型用于快速本地预测
- 自适应对数空间偏差头，通过在线梯度下降修正每文档LLM错误
- 基于置信度的LLM跳过，加速高可预测token
- 混合二进制格式NC06，扩展到任意二进制文件
- llama.cpp推理后端，单token解码比PyTorch快7倍
- 最多8个worker的并行多GPU压缩
- 原生KV缓存滑动窗口，每slide成本降低37倍

性能:
- alice29 (Canterbury Corpus): 0.918 bpb
- enwik8 (100 MB): 0.9389 bpb (比FineZip 1.024 bpb提升8%)
- 仅需~500 MB GGUF权重和~1.2 GB VRAM

L3: GPU-Native Learned Lossless Compression (SIGMOD 2026)

作者: 人民大学、清华大学
核心: 面向GPU的新型学习型无损轻量压缩格式
目标: 将学习型压缩真正融入GPU数据分析流程
能力: 压缩、解压、随机访问与查询处理的端到端设备端执行

LICO: SIMD-Aware Learned Inverted Index Compression (SIGMOD 2026)

作者: 人民大学、西南大学、HKUST(GZ)
核心: SIMD感知高性能学习型倒排索引压缩框架
特点: 利用SIMD指令加速学习型索引压缩

GPU加速类


FlashANNS (SIGMOD 2026)

作者: 浙江大学、华中科技大学
核心: GPU异步I/O流水线
突破: 消除存储-计算瓶颈的十亿级相似性搜索
创新: 异步流水线隐藏I/O延迟

GPU-Accelerated SQL Analytics on Compressed Data (arXiv 2506.10092)

作者: Zezhou Huang, Krystian Sakowski, Hans Lehnert等
核心: 直接在轻量级压缩数据上运行SQL查询
支持的编码: RLE、索引编码、位宽缩减、字典编码
关键创新:
- 多列RLE操作，无需解压
- 异构编码支持（不同列不同压缩方案）
- PyTorch张量操作实现跨设备可移植性
性能: 比商业CPU系统快一个数量级(10x)

ZipFlow (arXiv 2602.08190)

作者: Gwangoo Yeo, Zhiyang Shen, Wei Cui等
核心: 编译器框架优化GPU压缩数据传输
分类: 将压缩算法分为三种并行模式
优化: 每种模式采用通用调度策略
性能: 
- 比nvCOMP快2.08倍
- 比DuckDB快3.14倍 (TPC-H)

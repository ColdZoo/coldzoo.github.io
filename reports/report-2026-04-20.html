1. GPU Acceleration & GPU Database Papers


1.1 gMatch: Fine-Grained and Hardware-Efficient Subgraph Matching on GPUs

  • Authors: Weitian Chen, Shixuan Sun, Cheng Chen, Yongmin Hu, Yingqian Hu, Minyi Guo
  • Source: arXiv:2604.10601 [cs.DB], April 2026
  • Key Contributions:
  • Proposes a fine-grained execution model for GPU subgraph matching
  • Introduces warp-level batch exploration for improved execution efficiency
  • Implements lightweight load balancing to enhance scalability
  • Outperforms state-of-the-art methods (STMatch, T-DFS, EGSM) on diverse workloads
  • Performance: Scales to larger queries and datasets where existing methods fail
  • Link: https://arxiv.org/abs/2604.10601

1.2 ZipFlow: Compiler Framework for GPU Compressed Data Transfer

  • Authors: Gwangoo Yeo, Zhiyang Shen, Wei Cui, Matteo Interlandi, Rathijit Sen, Bailu Ding, Qi Chen, Minsoo Rhu
  • Source: arXiv:2602.08190 [cs.DB], February 2026
  • Key Contributions:
  • Compiler-based framework optimizing compressed data movement for GPU analytics
  • Classifies compression algorithms into three patterns based on parallelism
  • Provides end-to-end optimization across compression, transfer, and decompression
  • Performance:
  • 2.08× faster than nvCOMP
  • 3.14× speedup vs CPU-based DuckDB on TPC-H
  • Link: https://arxiv.org/abs/2602.08190

2. Data Encoding & Compression Papers


2.1 CLAD: Log Anomaly Detection on Compressed Data

  • Authors: Benzhao Tang, Shiyu Yang
  • Source: arXiv:2604.13024 [cs.LG], April 2026
  • Key Contributions:
  • First deep learning framework for log anomaly detection directly on compressed byte streams
  • Key insight: normal logs exhibit regular byte patterns after compression; anomalies disrupt these patterns
  • Architecture: dilated convolutional byte encoder + hybrid Transformer-mLSTM + 4-way aggregation pooling
  • Two-stage training: masked pre-training + focal-contrastive fine-tuning
  • Performance:
  • 0.9909 average F1 score (SOTA)
  • 2.72 percentage points above best baseline
  • Zero decompression overhead
  • Link: https://arxiv.org/abs/2604.13024

2.2 DecoupleVS: Vector Data and Index Storage Decoupling

Research Trends Analysis


Key Observations


  • GPU-Native Compression Formats Emerging: L3 (SIGMOD'26) represents a new class of GPU-native compression formats that co-design compression algorithms with GPU execution patterns.

  • Query-on-Compressed Becoming Standard: Multiple papers (GPU SQL on Compressed, CLAD) demonstrate direct query processing on compressed data without decompression, eliminating I/O bottlenecks.

  • Vector Search GPU Acceleration: SIGMOD 2026 features 5+ papers on GPU-accelerated vector search (FlashANNS, VecFlow-Chamfer, CMANNS, etc.), reflecting the importance of ANNS in modern RAG systems.

  • LLM-Database Integration Deepening: CoDec (SIGMOD'26) and several other papers show increasing focus on database-system perspectives on LLM serving and optimization.

  • FineZip Impact: Despite being from 2024, FineZip continues to be referenced as a key milestone for practical LLM-based compression, demonstrating 54× speedup over prior approaches.

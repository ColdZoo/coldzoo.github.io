# 蔡政的个人主页

> macOS Monterey 风格的全栈开发者个人主页

🔗 **在线访问**: https://caizheng.github.io/

## 技术栈

- HTML5 + CSS3
- 原生 JavaScript (无框架)
- macOS Monterey 设计语言
- 毛玻璃效果 (backdrop-filter)
- CSS 动画 + IntersectionObserver

## 特性

- 🎨 macOS Monterey 亮色系设计
- 🪟 窗口卡片 + 交通灯元素
- 📱 完全响应式布局
- ✨ 滚动淡入动画
- 🎯 底部 Dock 导航
- ⏰ 实时 Menu Bar 时间

## 本地预览

```bash
python3 -m http.server 8888
# 访问 http://localhost:8888
```

## 部署

本项目使用 GitHub Actions 自动部署到 GitHub Pages。

每次推送到 `main` 分支会自动触发部署。

## 自定义

编辑 `index.html` 中的以下内容：

- 姓名、职位、介绍
- 项目信息
- 工作经历
- 技能列表
- 社交链接

# 2026-04-01 工作记录

## sync_reports.py GITHUB_TOKEN 推送修复
- 问题根因：脚本用 `os.environ.get("GITHUB_TOKEN", "")` 读取环境变量，在自动化 shell 中该变量为空，导致 remote URL 变成 `https://ColdZoo:@github.com/...`，GitHub 拒绝空 token
- 修复方案：
  1. 新增 `get_github_token()` 函数，优先调用 `gh auth token`（成功率最高），fallback 读 `GITHUB_TOKEN` 环境变量
  2. `git_push()` 在每次 push 前动态获取 token、构造 remote URL，避免依赖全局空变量
  3. remote URL 改用 `x-access-token:` 前缀（GitHub 推荐格式）
- 验证：gh CLI 可正常获取 40 字符 token

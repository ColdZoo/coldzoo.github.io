## 每日自动同步脚本 (2026-03-27)

创建了全自动同步脚本 `/Users/adam/WorkBuddy/20260324123505/scripts/sync_reports.py`，实现：

1. **自动检测新报告** — 扫描 `db_research_reports` 目录，识别新增的 Markdown 文件
2. **智能标签分配** — 扫描正文关键词自动打标签（数据编码/GPU加速/编码+GPU/日常追踪）
3. **HTML 生成** — 将 Markdown 转换为带 macOS 风格的 HTML 页面
4. **博客列表重建** — 自动更新 `blog.html`（按日期降序，支持标签筛选）
5. **主页更新** — 同步主页博客板块（显示最新 3 篇）
6. **Git 推送** — 自动提交并推送到 GitHub gh-pages 分支

### 技术细节
- Token 通过环境变量 `GITHUB_TOKEN` 传入，避免硬编码被 GitHub Secret Scanning 拦截
- 使用 `.workbuddy/report_state.json` 记录已处理文件，避免重复转换
- 自动提取论文标题和摘要用于博客列表展示
- 支持灵活的文件命名：标准 `report_YYYY-MM-DD*.md` 或自定义文件名（用于独立翻译文章）

### 自动化配置
- **任务名称**: `sync-db-reports-blog`
- **执行时间**: 每日 21:00
- **工作目录**: `/Users/adam/WorkBuddy/20260324123505`
- **状态**: 已启用（ACTIVE）

### 使用方式
```bash
# 手动触发同步

# 传入 Token（自动化时会自动获取）
```
